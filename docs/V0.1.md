## 当前界面

- 主页：日期时间、校园入口、今日课程与插件启停。保留用户已有插件启停配置。
- 侧栏：主页、Agent、社区、已启用插件；底部插件市场（当前为本地管理）、应用设置、个人头像。默认 196px 展开，可拖动至 176–320px 并保存；56px 收起，中部分隔线开关，支持 Cmd/Ctrl + 反斜杠。分隔线双击复位，可聚焦后用方向键调宽。图标固定锚点、文字渐隐；界面即时响应，配置串行持久化。
- 个人：本机显示名称、个人头像、主页壁纸；进入校园账号管理。个人设置不修改学校返回的身份信息。
- 校园账号：读取、切换、移除已有账号与设置账号头像。新增页内添加 / 重新登录表单，支持直连探测与 WebVPN、验证码、短信 MFA、身份选择及保存账号密码；可单独删除已存密码。
- 应用设置：减少动态效果、时钟是否显示秒；独立模型服务配置。
- 模型服务：多配置增删改、默认项、厂商名称、协议、接口地址、模型和独立 API Key。编辑留空保留密钥，也可明确移除；允许主动导入旧版 Key。首次迁移补充 DeepSeek 预设（`https://api.deepseek.com` / `deepseek-flash`），已有默认项不变；删除后不会重复补回。仅保存配置，不宣称已连通模型，Agent 运行时仍属 V0.2。
- 社区：固定入口，显示尚未接入；没有模拟帖子或虚构同步状态。
- 本地插件管理：搜索、导入、排序、启停；完整课表和校园导航独立页面。
- 系统原生标题栏；没有学校、版本或插件数量页脚。完整 DIY 仍待后续版本。

## 存储与边界

普通配置包含个人显示资料、经 Rust 解码缩放的 PNG 头像 / 壁纸、应用偏好和原有插件设置。新增字段有默认值，可读取旧配置，不覆盖停用状态。

校园账号、可选保存的密码及会话保存在 AES-GCM 加密文件，模型服务另存加密文件，随机主密钥放系统凭据库。保存密码默认开启，可关闭；仅成功登录后持久化，前端只收到是否保存的标记，重新登录时由 Rust 直接取用。旧账号文件兼容缺省密码字段。模型配置列表不返回 API Key；旧版单个 Key 保留，可主动复制到新配置。服务地址禁止 URL 凭据、查询串与片段；远程要求 HTTPS，仅本机允许 HTTP。保存配置不会发起模型网络请求。

CAS / WebVPN / MFA 后端与课表 provider 既有逻辑保留，但真实校园认证、Windows 和正式签名公证尚未验收。
