## 当前界面

- 主页：日期时间、校园入口、今日课程与插件启停。保留用户已有插件启停配置。
- 侧栏：主页、Agent、社区、已启用插件；底部插件市场（当前为本地管理）、应用设置、个人头像。默认 196px 展开，可拖动至 176–320px 并保存；56px 收起，中部分隔线开关，支持 Cmd/Ctrl + 反斜杠。分隔线双击复位，可聚焦后用方向键调宽。图标固定锚点、文字渐隐；界面即时响应，配置串行持久化。
- 个人：本机显示名称、个人头像、主页壁纸；进入校园账号管理。个人设置不修改学校返回的身份信息。
- 校园账号：读取、切换、移除已有账号与设置账号头像。新增页内添加 / 重新登录表单，支持直连探测与 WebVPN、验证码、短信 MFA、身份选择及保存账号密码；可单独删除已存密码。
- 应用设置：减少动态效果、时钟是否显示秒；独立模型服务配置。
- 模型服务：多配置增删改、默认项、厂商名称、协议、接口地址、模型和独立 API Key。编辑留空保留密钥，也可明确移除；允许主动导入旧版 Key。首次迁移补充 DeepSeek 预设（`https://api.deepseek.com` / `deepseek-flash`），已有默认项不变；删除后不会重复补回。仅保存配置，不宣称已连通模型，Agent 运行时仍属 V0.2。
- 社区：固定入口，显示尚未接入；没有模拟帖子或虚构同步状态。
- 本地插件管理：搜索、导入、排序、启停；完整课表和校园导航独立页面。
- 系统原生标题栏；没有学校、版本或插件数量页脚。完整 DIY 仍待后续版本。

## 存储与边界

普通配置包含个人显示资料、经 Rust 解码缩放的 PNG 头像 / 壁纸、应用偏好和原有插件设置。新增字段有默认值，可读取旧配置，不覆盖停用状态。

校园账号、可选保存的密码、会话及模型服务统一保存在 `~/.xjtu-launcher/auth.json` 明文 JSON。旧 AES-GCM 文件和系统主密钥只用于首次导入，日常读写不再访问钥匙串。保存密码默认开启，可关闭；仅成功登录后持久化，前端只收到是否保存的标记，重新登录时由 Rust 直接取用。旧账号文件兼容缺省密码字段。模型配置列表不返回 API Key；旧版单个 Key 保留，可主动复制到新配置。服务地址禁止 URL 凭据、查询串与片段；远程要求 HTTPS，仅本机允许 HTTP。保存配置不会发起模型网络请求。

CAS / WebVPN / MFA 后端与课表 provider 既有逻辑保留，但真实校园认证、Windows 和正式签名公证尚未验收。

## 公钥解析修复（2026-10-19）

用户实测报“校园登录公钥格式发生变化”。已用学校返回的单行 Base64 PEM 格式复现：Rust 默认 PEM 读取按固定宽度折行，导致合法 RSA 公钥被拒绝，流程尚未提交凭据。改为识别 PUBLIC KEY / RSA PUBLIC KEY 边界、去除 Base64 空白，再严格校验对应 DER 结构；不降低 TLS 或 RSA 校验要求。

- 回归测试覆盖标准折行、单行、CRLF 与边界空白、PKCS#1，以及非法内容 / 标签不匹配拒绝；修复前单行样例失败，修复后通过。
- `live_campus_public_key_probe` 实际从学校读取公钥并完成本地测试加密通过，不提交凭据或发送短信。
- Clippy 全目标零警告、前端构建和独立 macOS App 打包通过；已重新打开修复版，真实账号认证继续由用户验收。
- 用户建议参考 `syxt.xjtu.edu.cn` 登录，复杂的微信 / 手机号登录可暂缓。已请求在内置浏览器打开该站；当前直接读取该站得到教学门户，另外读取统一认证页观察到手机动态密码与扫码逻辑。相关新增登录方式暂未实现，优先修通账号密码流程。

## 独立校园网页窗口（2026-10-19）

用户同意后，在 `codex/campus-browser` 实现：校园 HTTPS 链接用独立原生窗口打开，先从当前账号的加密快照导入未过期的学校 Cookie，然后按账号保存的直连 / WebVPN 路径访问。复用主界面现有链接组件，仅更新入口说明。

- `src-tauri/src/campus_browser.rs`：窗口创建、原生 Cookie 导入、菜单导航、同窗口校园跳转、临时会话隔离；窗口不具有启动器 IPC 权限。
- `src-tauri/src/network.rs`：网页路由支持学校域名；原认证 HTTP 客户端的窄域名白名单保持独立。
- 重新认证、账号切换、当前账号移除、退出或主窗口关闭时销毁校园窗口。窗口临时数据与加密账号文件分开；网页新增会话不会写回文件，也不向网页提供密码或业务令牌。
- 菜单“校园网页”包含后退（Cmd/Ctrl+[）、前进（Cmd/Ctrl+]）、刷新（Cmd/Ctrl+R）以及在系统浏览器打开。系统浏览器仍有自己的登录状态。
- 同一账号同一代会话复用窗口；`target=_blank` 校园链接转到当前窗口。复杂弹窗 / opener 通信、学校额外认证及逐站点兼容仍需验收。仅学校 HTTPS 标准端口在内置窗口打开。

验证：31 项 Rust 测试通过、2 项联网认证探测默认忽略；Clippy 全目标零警告。`cargo run --manifest-path src-tauri/Cargo.toml --example campus_browser_smoke` 已在 macOS 原生窗口验证 Cookie 导入、HttpOnly / Secure / path、两个账号存储隔离及关闭旧窗口。该检查只使用合成 Cookie，不读取用户凭据。真实网站单点登录与 Windows 实机尚未验证。

本轮独立 macOS App 构建、TypeScript / Vite 和格式检查通过，已重新打开新版并保持运行，等待用户对一网通办 / 思源学堂等真实网站验收。
