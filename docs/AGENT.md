## 目标结构

### 内置插件：Agent 设置

- 作为随应用发布的内置插件出现在侧栏（`cn.xjtu.agent-settings` 一类标识），不属于远端市场插件。
- 页面分区：
  - **模型服务**：沿用现有多厂商配置（openai-compatible / anthropic / gemini），从应用设置整体迁移。
  - **接入工具**：列出可提供给 Agent 的内置校园工具（课表、成绩、考试、考勤、校园卡等）及各自可用状态；MCP 工具随启用的 MCP 服务注入。
  - **MCP 服务**：已安装列表、启停开关、测试连接并查看工具、编辑命令/地址与凭据、移除。
  - **MCP 市场**：从插件服务端目录安装 MCP 服务，安装前展示将要执行的命令或访问的地址。
- 凭据（环境变量、请求头）保存在本地，界面只显示键名；编辑时留空表示保留原值。

### Agent 页面

- 对话区：流式回复、工具调用卡片（参数与结果）、失败时可直接重试。
- 顶部：新对话、历史记录、当前模型选择、进入 Agent 设置。
- 历史会话持久保存在本机，切换页面不中断进行中的回答；可取消。

### 插件市场

- 恢复为原有三分区（校园功能 / 远端市场 / 已安装），移除 MCP 标签页。

## 实现顺序

1. 新建 worktree，把 MCP 管理从插件市场迁出，建立 Agent 设置插件（模型服务迁移 + MCP 服务 + MCP 市场 + 接入工具）。
2. Agent 运行时：模型流式响应、工具循环、取消与重试、对话持久化；工具先接校园查询与已启用的 MCP 服务。
3. Agent 对话页接入运行时。
4. 后续另议：Skills、长期记忆、文件与命令工具。

## 数据与安全

- MCP 配置：`~/.xjtu-launcher/mcp.json`，含环境变量/请求头凭据，仅本机读取。
- 模型配置：沿用现有的加密文件与 `auth.json` 边界，不把 API Key 写入日志。
- 对话记录：`~/.xjtu-launcher/agent/conversations.json`；角色、Skills 与预设任务在 `presets.json`；全局记忆在 `memory.json`。
- 校园查询工具复用 `school_query` 的封闭枚举，不接受任意 URL；账号切换时旧请求必须按会话代次丢弃。
- Agent 的写工具只有两个。`campus_lms_submit`：`confirm=false` 只预览；`confirm=true` 才上传附件并提交。文件只允许用户明确指定的绝对路径、常见文档 / 代码 / 媒体扩展名，拒绝凭据目录与符号链接，单文件 100 MB、单次 200 MB。提交结果不明（网络中断、5xx）时不重试、不清理可能已被引用的上传，并提示用户到思源学堂确认；明确 4xx 拒绝才清理本次上传。`campus_evaluations_submit`：必须先由 `campus_evaluations_preview` 生成预览并拿到 `previewId`，再带 `confirm=true` 提交；预览 15 分钟过期，绑定账号与会话代次，结果不明时标记为未知且不自动重试。
- 本地 MCP 会启动子进程，安装或编辑时界面必须显示实际命令；不把市场目录里的命令当作可信输入静默执行。

## 尚未确定
