# 插件格式与使用

当前协议版本为 1。它先验证启动器如何发现、管理和展示插件，尚未形成最终脚本运行时。

## 添加插件

复制并修改仓库中的 `examples/campus-links/plugin.json`。桌面版打开“插件市场 → 已安装 → 导入本地插件”，选择包含该文件的目录。应用校验后仅复制清单到本机插件目录，不执行源目录中的程序。

导入后可以修改应用插件目录中的 `plugin.json`，点击“刷新插件”读取。已有 ID 不会被导入操作覆盖。已安装页支持启用和顺序调整，侧栏入口跟随启用状态；变更在重启后保留。打开插件右侧操作菜单可以移除外部插件；内置插件可停用，但不能卸载。停用插件后其页面和工具不可用；重新启用即恢复侧栏入口。

## 导航插件清单

```json
{
  "schemaVersion": 1,
  "id": "local.campus-links",
  "name": "校园导航",
  "version": "0.1.0",
  "description": "我的常用校园网站",
  "icon": "compass",
  "page": {
    "type": "links",
    "links": [
      {
        "title": "西安交通大学",
        "description": "学校主页",
        "url": "https://www.xjtu.edu.cn"
      }
    ]
  },
  "widget": true
}
```

- `id`：3–80 个字符，以字母或数字开头，允许小写字母、数字、点和连字符；禁止连续的两个点与路径分隔符。
- `schemaVersion`：必须为 `1`，未知字段/页面类型会被拒绝。
- `name`：1–30 个字符，`description` 最多 300 个字符。
- `page.type = links`：独立导航页面，最多 50 个 HTTP/HTTPS 链接。禁止文件、脚本协议和 URL 内嵌账号密码。校园 HTTPS 链接通过独立校园窗口打开，其他链接由系统浏览器打开。
- `widget = true`：在主页“我的插件”区显示入口卡片。目前不是任意自定义小组件。
- `icon`：预留图标标识，目前导航页统一显示指南针，课表显示日历。

文件最多 64 KiB。错误插件会被跳过并显示错误，不影响其他有效插件。对应用插件目录中的外部符号链接会进行限制。

## 内置主页主题插件

`plugins/cn.xjtu.home-theme/plugin.json` 声明 `page.type = homeTheme`，页面提供主页时钟风格（简约 / 醒目 / 等宽 / 卡片）和主页元素开关（问候与日期、时钟、今日课程、校园快捷入口、我的插件）。设置保存在 `config.json` 的 `homeClock` 与 `homeSections`，主页据此渲染；旧配置缺省为简约时钟和全部元素显示。

## 内置课表插件

`plugins/cn.xjtu.timetable/plugin.json` 声明 `page.type = timetable`，由编译进应用的 Rust provider 查询课表。内置插件同样可以启停和调整顺序，但不能由外部清单覆盖。自定义插件目前不能声明 timetable 页面或访问校园 token。

## 远端安装

“远端市场”从设置中的服务端读取目录，下载符合本协议的导航插件。更改地址需先点击“确认更改”并确认提示；保存后恢复只读。

客户端核对清单、最低应用版本、语义版本及 SHA-256 摘要。已安装插件记录来源，同 ID 的其他来源不会自动覆盖已有插件。新版本安装失败会保留原版本。远端安装记录保存在对应插件目录的 `installed.json`，包含清单及来源；它与本地导入的 `plugin.json` 分开识别。

目录服务运行方式与协议见 [插件服务说明](../tools/plugin-server/README.md)。插件包下载成功不代表客户端可以执行任意脚本或 Rust 动态库。

## 后续扩展

第三方校园业务、真正的可交互插件页面、独立主页小组件及 Agent 工具是期望能力。运行环境、权限授权、宿主 API 与版本兼容需后续实现；V0.1 的 JSON 协议不代表已支持这些能力，也不限制最终设计。
