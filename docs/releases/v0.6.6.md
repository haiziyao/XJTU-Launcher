# XJTU Launcher v0.6.6

发布日期：2026-11-10
状态：最新

## 摘要

新增社区广场导航页、字体库与工作台 MCP 读写，插件改为随应用发布的内置插件中心；修复思源学堂 MCP 作业上传因会话过期失败的问题。

## 新增

- **社区广场 v1**：侧栏「社区」改名「社区广场」，默认页是社团 / 课程攻略 / 校园生活 / 生涯分享 / 资源导航五个板块卡，中下部分是搜索框，旁边可切换普通 / Agent 模式。Agent 模式复用现有模型服务，需先在 Agent 设置基础页开启「开启搜索服务 Agent」；没有 Agent 插件、未开启开关、未配置模型或模型不可达时，Agent 按钮置灰并显示原因。板块页、详情页与真实内容仍在开发，点进任一块只显示「待开发」。
- **字体库**：字体美化页内嵌霞鹜文楷、霞鹜新晰黑、思源宋体、更纱黑体四个官方来源，下载前显示预览、下载中显示进度，更纱黑体在应用内解压 7z；也支持添加本机 TTF / OTF / WOFF / WOFF2。「应用」把字体设到全局、标题、正文、代码四个类别，字号等精细值不变；「取消应用」只恢复系统字体、文件保留；删除字体文件需确认。字体只在本应用内加载，不写入系统字体目录。
- **工作台 MCP 读写**：MCP / Agent 新增 `workbench_files` 与 `workbench_edit`，可浏览工作台、搜索文件、导入、新建文件夹、绑定作业与删除；编辑默认只返回预览，`confirm=true` 才执行，路径限制在当前账号的工作区根目录。
- **提交后自动归档**：作业正式提交成功后，把提交的文件复制并绑定到对应课程文件夹，按大小与 SHA-256 去重；归档失败只警告，不改变提交结果。开关在「设置 → 存储」，默认开启。
- **内置插件中心**：插件中心只展示随应用发布的内置插件，分校园广场 / 拓展发明 / 创新小港 / 已安装插件，行内开关控制启用，侧栏入口跟随启用状态；侧栏顺序可以拖拽调整。原来的远端插件市场、下载、安装与卸载全部移除。

## 修复

- **思源学堂 MCP 作业上传失败**：CAS 自动刷新会清空 `sites`、`direct_cookies` 与保存的密码；学校接口返回 HTTP 200 但内容是“会话已过期”时也没有识别。现在刷新不再丢会话、上传前识别过期载荷并续登一次，查询、预览与提交共用同一条 `renew_lms_session` 路径。2026-11-09 用真实账号经 MCP 提交计算机网络原理「第二章作业」成功（`submissionId` 2101649），已在截止前完成。
- **WebVPN 附件下载**：附件 302 到 `media.xjtu.edu.cn` 时按网络模式映射并保持精确来源校验，不再报“附件地址不受支持”。

## 变更

- 版本号 0.6.0 → 0.6.6。
- Agent 设置基础页新增「开启搜索服务 Agent」开关（`agentSearchEnabled`），默认关闭，控制社区广场能否把问题发给默认模型服务；`agentSidebarVisible` 只影响侧栏，不单独决定 Agent 搜索可用性。
- 插件从远端市场改为内置清单：`disabledPlugins` 只记录关闭的插件 id，插件设置存 `~/.xjtu-launcher/plugins/settings/`；旧配置里的 `pluginServer`、`checkPluginUpdates` 与桌面宠物字段只读取一次用于迁移。
- 官网首页、社区页与预览页改版（轮播 2.5 秒、`downloads.json` 版本占位不再写死）；官网文件不随安装包发布。

## 已知限制

- 社区广场只有导航页，五个板块点进去都是「待开发」；对外文案不能宣称已有真实社区内容。
- 更新源仍临时使用 HTTP + IP（P0），清单可能被篡改，安装包仍由 minisign 校验；拿到域名与证书后必须切回 HTTPS。
- macOS 包仍是 ad-hoc 签名，没有 Developer ID 与公证，首次打开可能提示“无法验证开发者”，需要右键 →「打开」。
- Windows 安装包当前没有 Authenticode 签名，SmartScreen 可能提示“未知发布者”；SignPath Foundation 免费签名流程已接入发布工作流，需等项目审批与仓库变量配置后才生效。
- 字体别名、字体选择弹窗改版与 Windows 字体加载尚未实现；评教页视觉仍未获准改版。
- 工作台没有拖拽导入，作业清单只保存在本机 `state/workbench`；图书馆、场馆、学籍页面还没有在校园网环境逐项联调。
