# XJTU Launcher v0.6.0

发布日期：2026-11-08
状态：最新

## 摘要

畅行校园改成「待办 / 通知 / 学习 / 学业 / 生活」一个工作区，各页接上真实数据；新增工作台（学期文件夹与作业提交）和回放截取插件；应用更新源迁到私有 OSS。

## 新增

- **畅行校园工作区**：左侧分区导航，右侧是当前分区的内容；会记住上次打开的分区。成绩、考试、空闲教室、全校课程、校历、评教、考勤、校园卡、体测、学籍、思源学堂、图书馆、场馆都已是应用内页面；成绩与考试可按学期筛选，校园课表按校园时区显示。查询结果先显示上次缓存再后台刷新，登录后会预取学期、成绩、考试、校历、通知、思源学堂课程与图书馆楼层。
- **待办与课程资料**：按思源学堂当前学期聚合每门课的未提交作业与资料附件，按逾期 / 今天 / 明天 / 本周分组；单次聚合约 14–17 秒，结果缓存 5 分钟，有请求失败时提示“列表可能不完整”。
- **工作台**：直接展示 `xjtu-launcher-file/workspace` 下你自己的文件夹，根目录是学期文件夹（如 `2026-2027 秋季学期`），其下是课程文件夹；可以在任意层级新建文件夹，在访达里改名或移动后仍按课程编号识别。课程作业可按学期查看、预览提交并上传课程文件夹里的文件，只交文字也可以；已截止且不允许补交时后端在上传前拒绝。
- **回放截取插件**：内置插件「回放截取」（`cn.xjtu.ppt-capture`，可停用），选课 → 选回放 → 播放 → 按固定间隔采样 → 框选 → 缩略图挑选 → 导出 PDF 或 ZIP。移植自 MIT 许可的 XJTU-PPT-Capture-Extension v2.5.2，许可与版权声明见 `THIRD_PARTY_NOTICES.md`。
- **思源学堂 MCP / Agent 工具**：`campus_lms` 新增 `overview`（本学期待办与课程资料）；新增只读工具 `campus_lms_download`，把附件存进可见的下载文件夹；`campus_lms_submit` 支持只交文字。
- **Agent 设置与 MCP 工具列表重做**：工具按「课程与成绩 / 学习 / 校园生活 / 通知」分组，标出读写类型，逐项开关；模型服务、绑定角色与工具清单在 Agent 设置里集中管理。
- **自定义入口图标**：`~/.xjtu-launcher/resources/icons/icons.json` 可以把主侧边栏、插件入口和畅行校园分区的图标换成自己的图片，见 `dev-docs/ICONS.md`。
- **侧栏重组**：主导航为「主页 / Agent / 社区 / 畅行校园 / 工作台」，只有调试用的「组件」入口已移除；「资料库」并入工作台。

## 修复

- **思源学堂时间**：前端与后端都改为按校园时区显示课程与活动的开始、结束时间。
- **WebVPN 下课程资料下载**：附件会 302 到 `media.xjtu.edu.cn`，旧代码只接受直连地址，WebVPN 模式直接报“附件地址不受支持”；现在按网络模式映射媒体地址，并在解码后仍校验精确来源。
- **筛选下拉宽度**：控件原来跟着当前值变宽变窄，长学期名在菜单里被截断；现在按最宽选项固定宽度，菜单可以完整显示。
- **学期标签**：思源学堂的 `term` 字段通常为空，待办与课程资料的学期只显示「2026-2027」；现在优先使用按开课日期推导的「2026-2027 秋季学期」，没有推导值时才退回学年。

## 变更

- 应用更新源改为 `http://8.152.100.169/latest.json`，由 nginx 交给签名网关后 302 到私有 OSS Bucket；0.5.x 客户端内置的旧路径会转发到同一清单，可以正常收到本版本。
- 版本号 0.5.2 → 0.6.0。

## 已知限制

- 更新源仍临时使用 HTTP + IP（P0），清单可能被篡改，安装包仍由 minisign 校验；拿到域名与证书后必须切回 HTTPS。
- 更新清单 `latest.json` 的 `notes` 为空，应用内「检查更新」不显示本次说明；更新内容以 GitHub Release 与版本记录为准。
- macOS 包仍是 ad-hoc 签名，没有 Developer ID 与公证，首次打开可能提示“无法验证开发者”，需要右键 →「打开」。
- Windows 安装包没有 Authenticode 签名，SmartScreen 可能提示“未知发布者”。
- 评教页视觉仍是旧样式，未获准改版；校园配色与其他页面的参考图仍在确认中。
- 工作台没有拖拽导入，作业清单只保存在本机 `state/workbench`，不自动回写用户的文件夹；没有 Windows 验证。
- 图书馆、场馆、学籍页面还没有在校园网环境下逐项联调。
