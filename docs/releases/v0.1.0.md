# XJTU Launcher v0.1.0

首个公开桌面版本，沿用原有侧栏、校园工作台与设置界面，提供 Windows、macOS 和 Linux 安装包。

## 下载选择

| 系统 | 安装包 |
| --- | --- |
| Windows 10 / 11 x64 | `x64-setup.exe`（推荐，支持中文、按当前用户安装）或 `x64_zh-CN.msi` |
| macOS 12+，Apple Silicon（M 系列） | `aarch64.dmg` |
| macOS 12+，Intel | `x64.dmg` |
| Linux x64（Ubuntu 22.04+） | `amd64.deb` 或 `amd64.AppImage` |

Windows 安装器会在缺少 WebView2 时联网安装运行时。Linux AppImage 下载后需添加可执行权限；部分系统需要安装 FUSE 2。deb 可通过 `sudo apt install ./下载的文件.deb` 安装并解析系统依赖。

## 功能

- 校园多账号登录、验证码 / 短信验证与 WebVPN 回退。
- 课表、校园导航与独立校园网页窗口。
- 插件管理、个人头像、壁纸和模型服务设置。
- Windows 中文安装器；三平台自动构建、版本一致性检查与 SHA-256 校验。

## 当前边界

- 这是 0.x 早期版本。Agent 对话、MCP、Skill 和社区同步尚未完成。
- 校园业务先前在 macOS 经用户实测；Windows / Linux 的实际校园登录与课表仍需要用户环境验收。
- 本次安装包未使用 Apple Developer / Windows 代码签名证书，macOS 也未公证，系统可能提示未验证的开发者。macOS 可在“系统设置 → 隐私与安全性”中确认允许打开。
- 暂未启用应用内自动更新，请从 GitHub Releases 下载新版。
- 校园凭据与 API Key 按现有设计保存在本机 `~/.xjtu-launcher/auth.json`，不上传到发布仓库。

`SHA256SUMS.txt` 包含全部安装包的校验值。
