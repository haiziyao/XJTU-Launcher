# XJTU Launcher v0.4.0

发布日期：2026-10-24
状态：历史

## 摘要

加入最小化桌宠、登录设备可信与课表自定义，Agent 与 MCP 的校园能力扩展到 33 个工具。内容取自原 GitHub Release 说明。

## 新增

- **最小化桌宠**：主窗口最小化后出现浮动桌宠与通知横条。四只内置社区角色，玻璃 / 深色玻璃 / 纯白横条；横条显示校园通知、Agent 完成与更新提示；双击桌宠可切换「只保留桌宠」或打开设置。
- **登录设备可信**：登录页新增「信任本设备」开关，一次短信验证后通常不再要求；同时修复验证码、短信两步验证与登录落地页识别。
- **课表自定义**：点课程块修改名称、教师、地点、周次、节次与颜色；可隐藏课程、添加只存在本机的课程，随时恢复学校原始内容。Agent 与 MCP 先返回预览，确认后才生效。
- **Agent 增强**：回复按 Markdown 渲染，右侧新增轮次刻度；新增评教预览 / 提交、思源学堂作业预览 / 提交、公开校园通知读取；MCP 校园工具扩展到 33 个。
- **主页教务处通知**：默认以可滚动、可按分类筛选的通知列表替换插件区；校园快捷入口修复（思源学堂浏览器兼容、图书馆新地址）。
- **页面标签底框**：可选外观，在「应用设置 → 外观与交互 → 页面标签」开启。

## 修复

- 校园网下登录误走 WebVPN，以及 WebVPN 登录后无法识别落地页的问题。
- 两步验证接口缺少 `status` 字段时误报验证码错误。
- 缓存按账号隔离，避免切换账号后读到上一账号的数据。

## 已知限制

- macOS / Windows 安装包未做系统代码签名，首次打开可能出现 Gatekeeper / SmartScreen 提示；Tauri 更新包的 minisign 校验不受影响。
- 上课提醒尚未接入：课表只有节次、没有具体上课时间。
- 尚未使用真实发布包做跨版本自动更新实测。

## 后续情况

- 0.4.0 是 0.5.x 之前最后可用的版本。0.5.0 与 0.5.1 均已撤回，当前版本为 [0.5.2](v0.5.2.md)。
- 0.5.2 已修复 macOS 签名，ad-hoc 签名可正常打开，但仍没有 Developer ID 与公证。
