# XJTU Launcher v0.7.0

发布日期：2026-11-13
状态：最新

## 摘要

前后端按业务域重新分层，校园工作区改用三栏主从版式；生活分区拆成「预约中心」与「个人画像」两个内置插件，个人画像新增概览页；修复场馆登录在校外 / 重启后失效与体测会话无法建立的问题。

## 新增

- **预约中心插件**（`cn.xjtu.campus-reservations`，默认启用）：图书馆与场馆两个页面，侧栏有独立入口。
- **个人画像插件**（`cn.xjtu.campus-profile`，默认启用）：概览、校园卡、体测、学籍档案四个页面。概览显示 GPA 与已修学分、学期绩点曲线、分数段、近 30 天消费结构与用餐 / 星期统计、身高体重与 BMI、体测单项换算分；数字都由已加载的成绩和流水在前端计算，并注明口径。
- **校园工作区 v2 版式**：分区导航、页头与内容区改为三栏主从，成绩、考试、评教、空教室、全校课程、校历、考勤、思源学堂、通知等页面按同一套结构重排；考勤从生活分区并入「学业」。
- **体测页面**：单项卡片与历年总分，右侧显示单项详情；学年筛选只列出真实有数据的学年。
- **社区广场**：板块卡可以收藏，顶部「我的收藏」按加入顺序排列，悬停或键盘聚焦时展开；「资源站点」页读取随应用打包的 `resources/community/sites.json`，首批登记 8 个学校服务地址，图标为自绘 SVG；用户可在 `~/.xjtu-launcher/resources/community/` 覆盖。
- **官网反馈页**：`website/feedback/` 与 `tools/site-api` 的 `POST /feedback`（P0，已部署到 `http://8.152.100.169/site/feedback/`，待用户验收）。
- **设计稿入库**：`docs/design/layout-v2/`、`profile-v1/`、`feedback-v1/` 的参考图与说明，均为示例数据。

## 修复

- **场馆在 WebVPN 下不可用**：场馆登录、查询与会话续期原先写死直连，账号处于 WebVPN 模式时没有可用路径；现在跟随账号当前模式，校外经 WebVPN `http-8080` 映射访问。
- **重启后场馆登录态失效**：查询发现会话过期时会用已保存密码自动重走 OAuth，并在首页确认 `userno` 已填后才保存 Cookie；`refresh_venue_session` 与查询重试共用同一条续期路径。
- **WebVPN portal 会话比服务会话先过期**：被弹回 portal 登录页时现在会重新登录 WebVPN 再重试一次，新的 portal Cookie 写回账号；思源学堂续期共用这一入口。
- **场馆非开放时段误报登录失效**：场馆在 8:40–21:40 之外关闭接口并跳转到自带提示页，原先被当成登录失效；现在跟随同源跳转，显示「晚上服务不可用（预约开放 8:40–21:40）」，页面用信息条而不是报错条呈现。
- **体测会话无法建立**：补齐 H5 回调里的启动参数与 `Index/checkLogin` 的 MD5 签名交换，保存 `sites.fitness.token`，会话过期时可以不弹密码直接重建旧的 PHP 会话。
- **学籍头像是空的时候**：学校头像加载失败会回退到用户自己设置的头像。
- **校园特性开关失效**：`require_school_feature` 之前校验的是不存在的插件 id，禁用校园相关插件不会拦住后台查询；现在按功能映射到 `cn.xjtu.campus`、`campus-profile`、`campus-reservations` 与 `timetable`。

## 变更

- 版本号 0.6.6 → 0.7.0。
- 前后端目录按 `AGENTS.md` 的分层重排：Rust 命令进 `src-tauri/src/commands/`，后端领域模块按 `core/`、`identity/`、`campus/`、`school/`、`agent/`、`plugins/`、`features/`、`workbench/` 分组；前端页面进 `src/features/<domain>/`，跨功能逻辑进 `src/shared/`，领域类型进 `src/types/`，全局样式进 `src/styles/`。
- 生活分区拆分后，原「畅行校园」不再有生活分区；已有的「常用」置顶和上次分区记忆按新插件分别保存。
- 场馆会话、图书馆会话继续按服务保存在 `~/.xjtu-launcher/auth.json` 的 `sites`，不需要用户重新登录。

## 已知限制

- 场馆与图书馆仍只读，预订 / 取消没有开放；评教与思源学堂作业提交仍要求预览后手动确认。
- 个人画像的人形仍是简笔占位；`Report/getItemDetails` 之外的体测历史字段没有实测，未展示。
- 更新源仍临时使用 HTTP + IP（P0），清单可能被篡改，安装包仍由 minisign 校验；拿到域名与证书后必须切回 HTTPS。
- macOS 包仍是 ad-hoc 签名，没有 Developer ID 与公证，首次打开可能提示“无法验证开发者”，需要右键 →「打开」。
- Windows 安装包当前没有 Authenticode 签名，SmartScreen 可能提示“未知发布者”。
- 官网反馈页（P0）已部署但待用户验收；应用内反馈入口（P1）等 HTTPS 后再做。
