# XJTU Launcher v0.5.0

发布日期：2026-10-25
撤回日期：2026-10-25
状态：已撤回

## 撤回原因

Tauri Updater 在 release 构建中拒绝非 HTTPS 端点，`plugins.updater` 反序列化失败后插件初始化中止，进程在打开窗口前退出。macOS 与 Windows 安装包都受影响；debug 构建只警告，所以开发时没有暴露。

## 处理

- 当天撤回 GitHub Release、`v0.5.0` 标签与镜像 `v0.5.0/` 目录。
- 修复写进 `tools/prepare-release.mjs`：只在端点为 `http:` 时写入 `dangerousInsecureTransportProtocol: true`，切回 HTTPS 后自动不写。
- 由 0.5.1 接替；0.5.1 又因 macOS 包未签名被撤回，当前版本为 [0.5.2](v0.5.2.md)。

## 影响

已安装 0.5.0 的用户无法在应用内更新（程序起不来），只能手动安装后续版本。

## 下载

已撤回，不再提供下载。请使用 [0.5.2](v0.5.2.md)。
