## 维护规则

- 发布前写记录，发布后补上实际验证结果；不能把计划或未执行的检查写成已验证。
- 记录必须区分自动测试、构建、真机 / 真实账号验证与未验证项。
- 撤回版本时更新本表状态，并在该版本记录中追加撤回原因与处理方式。
- 历史版本没有完整说明的，保持“原 Release 没有说明”，不根据印象补写。
