# XJTU Launcher v0.5.1

发布日期：2026-10-25
撤回日期：2026-10-30
状态：已撤回

## 撤回原因

macOS 安装包的应用包本身没有签名，只有二进制的链接器签名。Gatekeeper 判定应用损坏，打开时提示“已损坏，无法打开”，用户无法启动，也就无法通过应用内更新升级。

2026-10-30 已删除该版本的 GitHub Release、`v0.5.1` 标签与镜像 `v0.5.1/` 目录，并由 [0.5.2](v0.5.2.md) 接替。

## 当时发布的内容

- 修复 0.5.0 在 Windows 与 macOS 上打不开的问题：0.5.0 的发布配置带着临时 HTTP 更新源，release 构建启动时被更新插件拒绝（`updater` 插件初始化失败），窗口还没出现进程就退出。发布脚本改为只在 HTTP 端点下显式放开这一限制，切回 HTTPS 后自动恢复严格校验。
- 功能与 0.5.0 一致。0.5.0 的 Release 说明已随该版本撤回，仓库没有保留完整功能清单。

## 影响与处理

- macOS 用户如果已经安装了 0.5.1，无法在应用内更新，请手动下载 0.5.2 覆盖安装。
- 仍然保留的 0.5.1 安装包不要作为测试基线，也不要再分发。
- 该版本没有解决 macOS 签名问题；修复与验证记录见 [0.5.2](v0.5.2.md)。

## 下载

已撤回，不再提供下载。请使用 [0.5.2](v0.5.2.md)。
