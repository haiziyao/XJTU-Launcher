# 开发约定手册

更新于 2026-10-19。用户当次明确要求优先于历史文档；已授权的工作继续完成，不反复确认。

## 产品方向

面向学生的本地校园客户端，优先 macOS 和 Windows。主体使用 Rust + Tauri 2 + Vue 3 + TypeScript，承载校园账号、主页、插件与 Agent。不建设独立启动器平台账号服务端；插件市场服务端可以独立部署。

校园业务优先研究 XJTUToolBox，再按本项目结构适配。参考仓库中的功能、测试数据或设计图都不能被写成已在本项目完成。

## 设计与组件

1. 新前端先给具体参考图，再等用户明确认可设计并同意开始实现。讨论功能、确认框架和要求出图均不代表实施授权。
2. 最新已认可客户端是 Claude 修改后的基线及后续获准调整；已有组件优先复用，不临时另造视觉系统。
3. 插件市场 v2 七张稿已获准；Agent 与评教旧稿仍需调整。审批范围必须明确，不按关键词扩大。
4. 保持桌面应用观感与简洁信息密度，使用原生标题栏。不要添加无意义状态灯、页脚、宣传卡片或占位演示对话。
5. 默认以文字呈现资料，用户操作后再进入编辑态。侧栏使用统一图标，开关居分隔线中部，收起为紧凑图标栏。
6. 新增通用交互优先抽成 `src/components/ui/` 组件；颜色、间距、圆角和动效沿用现有 token。
7. 按钮统一使用 `UiButton`（文字）与 `UiIconButton`（纯图标），不直接写 `.btn` 类，也不按页面另造图标按钮；变体、尺寸和例外控件见 [按钮与通用控件](UI_COMPONENTS.md)。

## 数据与账号

- 凭据按用户决定存于 `~/.xjtu-launcher/auth.json`；不恢复系统钥匙串作为日常依赖。保存密码可选，接口不回读已存密码。
- 配置及凭据原子写入。新字段提供默认值，保持既有用户偏好；读取失败报告错误并保留原文件。
- 切换 / 删除账号、重新认证及退出时处理旧窗口和进行中的请求。缓存与异步返回必须关联账号及会话代次。
- 日志与截图不包含密码、令牌、Cookie、API Key 或私钥，测试优先使用合成数据。
- 不将校园凭据发送给插件市场服务。学校额外认证和过期状态应真实反馈。

## 插件与更新

- 启用控制插件是否运行；侧栏入口跟随启用状态，不再单独提供“侧栏显示”开关。
- 设置中插件服务地址默认只读。点击“确认更改”后展示危险提示，确认才进入编辑；保存或取消后重新锁定。
- 包版本、兼容性、摘要和来源必须验证，下载失败保留旧版本。已安装的同 ID 插件不能被另一来源无提示替换。
- 当前远端只支持声明式导航；任意执行代码的插件运行时需要独立设计，不能借下载清单宣称已经实现。
- 应用更新与插件更新来源独立；发布私钥仅进入 Secret。实际安装前检查正在执行的校园、账号和插件任务，未来 Agent 任务也要接入。

## 校园操作与验收

- 查询与提交分开。评教先显示真实问卷对应的完整答案，用户主动提交后才发送。
- 批次结果逐项记录；网络结果不明不能自动重发，取消只停止后续请求，不宣称撤回已发送内容。
- 小修改直接说明，大批修改后统一测试和构建；不因每次改一行而反复启动应用。
- 验收使用真正的 Tauri App，并交付可独立运行的包。用户查看时保留窗口。
- 报告区分“已实现”“测试通过”“真实账号验证”“用户验收”；明确未部署的服务和未测试的平台，不把计划写成完成状态。
