## 版本发布说明

- [版本记录索引](releases/README.md)：每个版本的日期、状态与内容概要。
- [v0.6.6](releases/v0.6.6.md)：当前最新版本，社区广场导航页、字体库、工作台 MCP 读写与内置插件中心。
- [v0.6.0](releases/v0.6.0.md)：畅行校园工作区、工作台与回放截取插件。
- [v0.1.0](releases/v0.1.0.md)：首个公开桌面版本的下载选择、功能与边界。

每次发版都要新增一份 `releases/v<版本>.md`，写清改动、验证程度与已知限制，再登记到索引；规则见 [约定手册](../dev-docs/CONVENTIONS.md#6-分支提交与发布)。下载地址只维护在根目录 README。
