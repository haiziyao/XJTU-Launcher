## 注意

- **`mcp-codex.png` 中有「提交结果：失败」**：这是 2026-11-09 修复 MCP 作业上传前的旧会话。修复后已用真实账号经 MCP 提交成功（`submissionId` 2101649），但没有留下同场景的成功截图。若用于「用 MCP 完成作业」的宣传，需换成成功提交的会话截图；否则只能按「MCP 调用与异常说明」表述，不能宣称提交成功。
- **`community.png` 只有导航页**：五个板块的内容仍在开发中，点进任一板块只显示「待开发」；搜索区下方显示「未开启搜索服务 Agent」。不能据此宣称社区已有丰富内容，正文文案应写成「社区广场（板块页开发中）」。
- **`home-wallpaper-font.png` 的壁纸是用户自备图片**，公开对外宣传前需确认该图片的使用授权。
- `campus-tools.png` 是真实账号的待办数据，含课程名与作业名，不含姓名、学号；对外使用前确认作业信息可以公开。
