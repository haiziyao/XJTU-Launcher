# 字体库 v1（2026-11-10 实现，待用户验收）

- `reference.png`：字体美化页内嵌字体库的早期参考图；实现时按用户反馈压缩了行高，去掉了别名的铅笔按钮，改为与上方设置行协调的紧凑行。
- `backlog/font-picker.png`：字体区域弹窗的改版参考，**未实现**。
- `backlog/alias-dialog.png`：字体别名编辑，**未实现**。

已确认并实现的决定：

- 字体只在本应用内用 `FontFace` 加载，不写系统字体目录，不需要管理员权限。
- 从官方发布源下载，校验 SHA-256；更纱黑体使用官方 7z 包，应用内解压后使用。
- 字体库放在字体美化页，上方保留五个区域的精细化设置。
- 「应用」默认把所选字体应用到全部五个区域；字号、字重、行高、字距保持不变。
- 支持从本机添加 `.ttf` / `.otf` / `.woff` / `.woff2` 字体文件；同一文件重复添加时复用已有条目。
- 字体库行使用与上方 `SettingRow` 相同的行结构、分隔线和按钮样式，左侧是紧凑预览图；下载时在行内显示真实进度条，解压时显示不确定进度。
- 首批字体：霞鹜文楷、霞鹜新晰黑、思源宋体、更纱黑体。

未实现，已加入 [`dev-docs/planning/need-do.md`](../../../dev-docs/planning/need-do.md) 的「未来 / 未排期」：

- 字体别名：给下载或本地字体起别名，并让别名出现在字体选择中。
- 界面字体具体设置 / 字体选择弹窗改版：当前仍沿用原有的输入框 + 候选列表，只把已安装字体的原名加进候选。
