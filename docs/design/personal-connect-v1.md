# 个人页开放接口 v1（MCP 模式）

状态：待用户确认（2026-10-23）。未获准前不实现页面。

参考图：[personal-connect-v1.png](personal-connect-v1.png)。按最终样式在真实窗口中渲染后截取，只包含新增分组；截图时临时隐藏壁纸并使用示例数据，不含账号与壁纸个人信息。

## 目标

个人页底部新增“开放接口”分组，提供 MCP 模式和 Web 模式。

- 本轮只实现 MCP 模式：让 Claude Code 等编程 Agent 连接启动器，直接调用已经实现的校园查询。
- Web 模式先不实现：只占位，显示“尚未实现”，没有假地址或假开关。
- 按用户要求，编程 Agent 不做身份认证；服务只监听本机回环地址。

## 页面

位置：个人页“校园身份”之后，沿用 `SettingGroup` / `SettingRow` / `IconTile` / `UiSwitch` / `UiButton`。

### MCP 模式

- 行标题 `MCP 模式`，说明“让 Claude Code 等编程 Agent 连接后直接查询课表、成绩、考试与校园卡。”，行尾为开关。
- 打开后展开三行内容：
  - 地址：`http://127.0.0.1:39217/mcp`，右侧“复制”。
  - 连接命令：`claude mcp add --transport http xjtu http://127.0.0.1:39217/mcp`，右侧“复制”。
  - 概况：`已开放 14 个工具 · 只读查询 · 仅本机访问`，右侧“查看工具”展开工具名称与说明。
- 关闭开关即停止监听，地址与命令收起。
- 异常状态只在概况行显示具体原因（端口被占用、校园账号未连接），不能显示“运行中”或“已连接”的假状态；未启动时地址不可复制。
- 分组脚注：“仅在本机监听，不经过启动器账号；本机任何程序都能调用已开放的工具。”

### Web 模式

- 行标题 `Web 模式`，说明“在浏览器中打开只读的校园数据页面。”，图标为 `Globe`。
- 行尾显示“尚未实现”标签，整行不可操作。

## 服务端

- 传输：MCP Streamable HTTP（JSON-RPC 2.0），入口 `POST /mcp`；`GET /mcp` 返回 405，不使用会话与 SSE 推送。响应为 `application/json`。
- 监听：仅 `127.0.0.1`，固定端口 `39217`。端口被占用时开关回到关闭并显示错误，不静默换端口。
- 生命周期：用户打开开关时启动，关闭开关或退出应用时停止。开启状态写入本地配置，下次启动应用时恢复监听；从未开启过就不监听。
- 协议方法：`initialize`、`notifications/initialized`、`ping`、`tools/list`、`tools/call`；未知方法返回 JSON-RPC 错误。
- 工具：复用 `agent::tools::builtin()` 的 14 个只读校园工具（课表、学期、成绩、考试、校历、考勤流水与记录、校园卡余额与流水、体测概览与成绩、空闲教室选项与查询、全校课程）。不转发已配置的外部 MCP 服务，避免递归，也不暴露任何写操作（评教、预订、提交作业均不在内）。
- 身份：使用当前校园账号会话；未登录时工具返回明确错误。不读取也不返回密码、Cookie、API Key。
- 风险：不做请求认证意味着本机任何进程都能读取当前账号可见的校园数据。按用户决定接受该风险，但只绑定回环地址，不监听局域网，并在页面脚注写明。

## 实现拆分
