# 个人页开放接口 v1（MCP 模式）

状态：已获用户确认（2026-10-23），已实现。确认内容包括分组与文案、端口可修改（默认 `39217`）、14 个查询工具，以及工具可按需开放、查看工具时显示名称、说明、分类与可达性。

参考图：[personal-connect-v1.png](personal-connect-v1.png)。按最终样式在真实窗口中渲染后截取，只包含新增分组；截图时临时隐藏壁纸并使用示例数据，不含账号与壁纸个人信息。

## 目标

个人页底部新增“开放接口”分组，提供 MCP 模式和 Web 模式。

- 本轮只实现 MCP 模式：让 Claude Code 等编程 Agent 连接启动器，直接调用已经实现的校园查询。
- Web 模式先不实现：只占位，显示“尚未实现”，没有假地址或假开关。
- 按用户要求，编程 Agent 不做身份认证；服务只监听本机回环地址。

## 页面

位置：个人页“校园身份”之后，沿用 `SettingGroup` / `SettingRow` / `IconTile` / `UiSwitch` / `UiButton`。

### MCP 模式

- 行标题 `MCP 模式`，说明“让 Claude Code 等编程 Agent 连接后直接查询课表、成绩、考试与校园卡。”，行尾为开关。
- 打开后展开：
  - 端口：可编辑，默认 `39217`；点“应用”在 `1024-65535` 范围内重启监听。新端口占用时回到原端口并显示原因，不静默换端口。
  - 地址：`http://127.0.0.1:<端口>/mcp`，右侧“复制”；只显示实际在监听的地址。
  - 连接命令：`claude mcp add --transport http xjtu <地址>`，右侧“复制”。
  - 概况：`已开放 N 个工具 · 仅本机访问`，右侧“查看工具”展开工具清单。
- 工具清单：按简单分类分组（课程与成绩、考勤、校园卡、体测、教室与校历），每行依次为勾选框、名称、说明与状态标签。取消勾选会立即把该工具从 `tools/list` 与 `tools/call` 中移除，选择写入本地配置；未知工具名在配置加载时被忽略。
- 可达性：状态标签由三件事决定，不用网络探测冒充“已连接”。
  - `服务未启动`：开关已开但监听失败。
  - `未开放`：用户取消了勾选。
  - `需登录校园账号`：工具需要当前校园会话，而账号未连接（校历为公开接口，不受影响）。
  - `可达`：服务在监听、工具已开放且所需会话可用。
  - “检查可达性”单独执行一次学期查询，只显示“校园会话可用”或具体失败原因，不展示查询结果细节。
- 关闭开关即停止监听，地址、命令与工具清单收起；开启失败时开关不写入配置，并在行下显示端口错误。
- 异常状态只在概况行显示具体原因（端口被占用、校园账号未连接），不能显示“运行中”或“已连接”的假状态；未启动时地址不可复制。
- 分组脚注：“仅在本机监听，不经过启动器账号；本机任何程序都能调用已开放的工具。”

## 服务端

- 传输：MCP Streamable HTTP（JSON-RPC 2.0），入口 `POST /mcp`；`GET /mcp` 返回 405，不使用会话与 SSE 推送。响应为 `application/json`。
- 监听：仅 `127.0.0.1`，端口来自配置 `mcpServerPort`（默认 `39217`，用户可改）。端口被占用时保留原监听并显示错误，不静默换端口。
- 生命周期：用户打开开关时启动，关闭开关或退出应用时停止。开启状态与端口写入本地配置，下次启动应用时恢复监听；从未开启过就不监听。
- 协议方法：`initialize`、`notifications/initialized`、`ping`、`tools/list`、`tools/call`；未知方法返回 JSON-RPC 错误。
- 工具：复用 `agent::tools::builtin()` 的 14 个校园工具（课表、学期、成绩、考试、校历、考勤流水与记录、校园卡余额与流水、体测概览与成绩、空闲教室选项与查询、全校课程）；当前都是查询，后续可以加入写操作（如评教、预订），传输层不做“永久只读”限制。用户可在页面取消勾选，未勾选的工具不进入 `tools/list`，调用也会被拒绝；选择保存在配置的 `mcpServerDisabledTools` 中；读取配置失败时返回 JSON-RPC 错误，不静默放开工具。不转发已配置的外部 MCP 服务，避免递归。
- 身份：使用当前校园账号会话；未登录时工具返回明确错误。不读取也不返回密码、Cookie、API Key。
- 风险：不做请求认证意味着本机任何进程都能读取当前账号可见的校园数据。按用户决定接受该风险，但只绑定回环地址，不监听局域网，并在页面脚注写明。
