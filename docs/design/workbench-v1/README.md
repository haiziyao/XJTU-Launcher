# 工作台 v1：学期文件夹 + 文件树

2026-11-08 用户批准设计并开工；同日完成实现并接入侧栏，macOS 开发版已用真实账号看过学期视图、课程视图与提交预览。**用户验收尚未完成**，Windows 未验证。

## 设计前提

- 工作台依托**学期管理**，不按学年分组；学期名形如 `2026-2027 秋季学期`。
- 根目录是学期文件夹，其下是课程文件夹；右侧文件树可以展开 / 收起，用户也可以自己建文件夹。
- 中间区域由选择驱动：选学期看课程卡片，选课程 / 文件夹看作业清单与文件列表。
- 文件显示的是用户磁盘上的真实文件夹，应用不另建私有文件库；在访达里改名、移动同样生效。
- 课程身份用课程编号（`subject_code`，缺省 `code`），文件夹名是用户自定义的显示名（计组、计网）。
- 作业清单自动同步自思源学堂，保存在应用内，不写进用户文件夹。

## 实现状态

已实现：

- 顶部「工作台 + 学期 + 课程数 · 文件数 · 未交数 · 同步时间」，搜索、新建文件夹、添加文件、刷新。
- 右侧文件树：学期 / 课程 / 普通文件夹三种节点，按层级缩进、可展开收起，显示递归文件数；课程节点带原名小字。
- 学期视图：课程卡片（文件 / 文件夹 / 作业 / 未交），点卡片进入课程。
- 课程视图：课程编号与原名、作业清单（截止、状态、提交 / 重新提交、已截止）、文件表格（打开、在访达显示、删除前确认）。
- 普通文件夹视图：面包屑、文件列表；根层「未归类」也能正常显示。
- 同步：`workbench_sync` 建学期与课程文件夹，作业清单存 `state/workbench/<账号>.json`。
- 提交：选文件 → 预览 → 用户确认后上传；已截止作业不显示入口，结果不明不重试。

暂未实现（参考图里有、代码里没有）：

- 课程的学分、教师、教学班——这些字段还没接进工作台数据。
