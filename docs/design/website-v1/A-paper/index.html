01 — 能力

不是把网页
塞进客户端

Rust 直接对接校园系统，查询走原生请求。评教和作业提交先预览、再确认，不做你没同意的写操作。

01

一处登录

密码、短信验证码、扫码三种方式；多账号保存，WebVPN 自动回退，凭据只存在本机。

02

课表与成绩

今日课程与完整学期课表，按周切换；成绩、考试、考勤、校园卡、空闲教室一页查完。

03

思源学堂

作业、学习资料、课程回放、讨论按类型切换；附件可另存，录播课直接取回放地址。

04

Agent

用自然语言查询校园数据；改课表、交作业、评教都会先给出预览，你同意后才执行。

05

本机 MCP

打开 MCP 模式后，Claude Code 等编程 Agent 可以在本机直接调用同一批校园工具。

06

插件与更新

课表、畅行校园、主页主题以插件形式出现；应用更新带签名校验，可更换镜像源。

02 — 校园

一个窗口，
看完今天所有事

不只是课表。今天上什么、还有哪门作业没交、这周考勤有没有异常，打开就知道。数据只在你自己的机器上解密。

  • 原生 Rust 请求，不内嵌浏览器登录页
  • 切换账号即关闭旧窗口，缓存按账号隔离
  • 所有写操作先预览，结果不明不自动重试

04 — 安装

第一次打开

macOS

  1. 打开 DMG，把 XJTU Launcher 拖进「应用程序」。
  2. 首次打开提示「无法验证开发者」时，去「系统设置 → 隐私与安全性」，底部点「仍要打开」。
  3. 每个新版本确认一次，之后直接启动。

Windows

  1. 运行 setup.exe，按向导完成安装。
  2. 出现「Windows 已保护你的电脑」时，点「更多信息」→「仍要运行」。
  3. 安装完成后从开始菜单启动。

系统提示不代表安装包损坏。介意的话，先用上面的 SHA256 核对文件，再从本站或 GitHub Release 打开。
