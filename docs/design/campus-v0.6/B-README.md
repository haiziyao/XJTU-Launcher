## 结构

- **一级标签**：待办 · 通知 ｜ 学习 · 学业 · 生活；右侧数字是待办数与未读数，不用红点。
- **二级标签**：只在"学习 / 学业 / 生活"下出现；学习 = 思源学堂 / 课程资料（本机资料库已移到侧栏「工作台」），学业 = 成绩 / 考试 / 评教 / 空闲教室 / 全校课程 / 校历，生活 = 校园卡 / 图书馆 / 场馆 / 考勤 / 体测。
- **学籍档案**移回个人页，不再占校园导航（沿用 LAYOUT §2.1、§9.13）。
- 分区标题行保留"更新于"和信息量说明（文件数、课程数），右侧放搜索与视图切换。

## 内容规则

- 课程卡片：课程名、教师 / 课程号 / 学分、未交 / 资料 / 回放数量、下次截止、最近活动；点击进入课程。
- 课程内部、待办、成绩、考试、全校课程：30–36px 行高的表格，表头吸顶，数字右对齐等宽。
- 每个页面补一块跨课程内容（最近更新 / 即将截止），避免下半屏整块空白。
- 卡片只用于"课程"这一层；文件和作业不单独做卡片。
