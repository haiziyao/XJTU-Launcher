# v0.6.0 校园页面与资源接口清单

更新：2026-10-30
状态：调查清单。只列事实与缺口，不含布局方案；排版由用户决定。
范围：应用内所有与校园数据相关的页面、主页卡片、侧栏入口和外部跳转。设置项只列与校园数据有关的入口。
逐项功能（每个页面里能做什么、缺什么、频率）：见 [FEATURES.md](FEATURES.md)。

口径：

- **接口**指应用内 Rust 命令与 `school_query` 的 `Query` 类型；学校系统内部的 HTTP 路径不逐条展开，协议记录见 [CAMPUS_FEATURES.md](../../../dev-docs/features/CAMPUS_FEATURES.md)。
- **频率**是按校历、任务周期和页面性质做的产品估算，不是埋点数据。项目没有遥测，不能把估算写成实测。
- **外链**指点击后进入内置校园网页窗口、系统浏览器或下载文件，而不是在当前页面直接展示。

## 6. 外部跳转清单

统一入口是前端 `bridge.openUrl()` → Rust `open_external`：

- `*.xjtu.edu.cn` 的 HTTPS 地址：用当前账号 Cookie 打开内置校园窗口。
- 其他 HTTPS：交给系统浏览器。
- 代码中没有 `window.open` 或 `shell.open`。

| 入口                      | 地址来源                            | 当前去向              | 是否属于要移除的校园外链 |
| ------------------------- | ----------------------------------- | --------------------- | ------------------------ |
| 主页“一网通办”            | `src/shared/domain.ts` `campusLinks`       | 内置校园窗口          | 是                       |
| 主页“教务系统”            | `campusLinks`                       | 内置校园窗口          | 是                       |
| 主页“思源学堂”            | `campusLinks`                       | 内置校园窗口          | 是                       |
| 主页“图书馆”              | `campusLinks`                       | 内置校园窗口          | 是                       |
| 教务处通知每条            | `campus_notices` 返回的 `url`       | 内置校园窗口          | 是（正文）               |
| 校历每行                  | `Query::Calendar` 返回的图片地址    | 内置校园窗口          | 是（图片）               |

| 思源学堂“打开附件”        | `lms_open_file`                     | 内置校园窗口          | 是（可改为页内预览）     |
| 自定义 `links` 插件每一行 | 插件 `page.links`                   | 内置窗口 / 系统浏览器 | 不是内置页面，另行决定   |
| Agent 回复中的链接        | 模型输出                            | 内置窗口 / 系统浏览器 | 不是校园页面             |
| 更新发布页                | 固定 GitHub 地址                    | 系统浏览器            | 不是校园数据             |

## 8. 频率分层（估算）

| 层级        | 页面 / 能力                                      | 依据                                          |
| ----------- | ------------------------------------------------ | --------------------------------------------- |
| 每天多次    | 主页今日课程、课程表、Agent（使用 Agent 的用户） | 上课与查课是日常动作；Agent 取决于用户习惯    |
| 每天 / 每周 | 通知、思源学堂作业、校园卡余额                   | 通知与作业有持续更新；校园卡是日常消费        |
| 每周 1–3 次 | 空闲教室、图书馆座位、场馆（有运动习惯的用户）   | 自习与运动场景                                |
| 每学期高峰  | 成绩、考试、评教、校历、全校课程                 | 出分、考试周、评教截止、开学 / 选课，时间集中 |
| 每年 / 按需 | 体测、学籍、考勤                                 | 体测每年一次；学籍与考勤按事务需要            |
| 按需 / 低频 | 个人页、插件中心、应用设置                       | 配置类操作                                    |

## 9. 要移除外链，还缺什么

| 资源              | 现状                                   | 原生展示需要的能力                                           |
| ----------------- | -------------------------------------- | ------------------------------------------------------------ |
| 一网通办          | 只有主页外链，没有后端适配             | 需要先研究办事大厅的页面结构与接口；没有现成 `Query`         |
| 通知正文          | 列表只返回标题、分类、日期、链接       | 需要抓取并解析正文，或接受仍然跳转原文                       |
| 校历              | 只返回图片地址，点击进校园窗口         | 需要把图片下载到本地并在页面内渲染；或解析成结构化日期       |
| 思源学堂回放      | 返回 RMS 播放地址，点击外链            | 需要内嵌播放器、媒体代理或继续使用网页窗口                   |
| 思源学堂附件      | 打开走校园窗口，下载走原生保存         | 需要 PDF / 图片 / 文本的页内预览；其他格式仍需下载或外部打开 |
| 图书馆 / 场馆预约 | 只有只读接口，没有预订 / 签到 / 取消   | 需要新增学校系统写接口，且必须遵守预览与确认规则             |
| 作业提交          | 后端与 Agent 已有，页面没有入口        | 需要页面级上传、预览、确认、结果不明不重试                   |
| 课程考勤          | 接口存在，页面没有视图                 | 需要按课程 / 日期展示的页面                                  |
| 已评评教          | 接口支持 `finished:true`，页面只用未评 | 需要“已评 / 未评”切换                                        |
| 多栏目通知        | 7 个栏目，主页只用 `dean`              | 需要栏目切换或独立通知页                                     |

## 10. 文档差异
