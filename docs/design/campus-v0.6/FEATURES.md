# v0.6.0 校园功能颗粒清单

更新：2026-10-30
状态：功能调查。按“用户实际要做的事”拆分到最小动作，不按页面模块罗列，也不含布局方案。
配套：[页面与资源接口清单](INVENTORY.md)、[功能与接口规格](SPEC.md)、[排版规定](LAYOUT.md)。

说明：

- 这里的“功能”是一次可独立完成的操作，例如“看某门课有哪些作业”“判断某个作业是否已交”“下载一个附件”“提交一次作业”，不是“思源学堂页面”这种整页概念。
- `已实现` 指代码里已有页面入口和请求路径；`仅 Agent` 指只有对话工具能做、页面没有入口；`后端有` 指 Rust / Query 已支持但页面没接；`无接口` 指本项目还没有适配（学校侧可能有协议，见各行说明）。
- 除特别注明外，校园页大多只做过单元测试和编译检查，**没有用真实账号逐项验收**。下面的“已实现”不等于“真实账号验证通过”。
- 频率是按校历、作业周期和校园场景做的估算，应用没有埋点，不能当作实测数据。

频率图例：

| 标记        | 含义                                          |
| ----------- | --------------------------------------------- |
| 每天多次    | 打开应用就会看，或一天内反复操作              |
| 每天        | 每天一次左右                                  |
| 每周 2–5 次 | 学期内的常规高频                              |
| 每周 1 次   | 每周固定查看                                  |
| 每学期高峰  | 平时接近零，出分 / 考试 / 评教 / 选课期间集中 |
| 每学期 1 次 | 开学、注册、期末等节点                        |
| 每年        | 体测、学籍核对等年度事务                      |
| 按需        | 有问题才查，平时不打开                        |

## 1. 先看任务链：现在断在哪

### 1.1 作业链

目标：打开就知道“哪门课、哪个作业没做”，看要求和附件，提交，之后看批改。

当前最短路径：畅行校园 → 思源学堂 → 选课程 → 作业分类 → 选活动 → 详情。

断点：

1. **没有跨课程的“未交作业”视图。** 课程活动列表只返回 `id / 类型 / 标题 / 起止时间 / 是否发布 / 是否小组作业`，没有“我是否已提交”。要判断只能逐门课、逐个作业打开详情看 `submitCount`，请求量是课程数 × 作业数。
2. **列表不显示“已截止 / 可补交”。** 后端详情其实已经返回 `closed`、`resubmitOpen`、`allowRetract`、`mode`，前端类型没有声明，页面也没有显示。
3. **页面不能提交作业。** 上传、预览、正式提交只有 Agent 的 `campus_lms_submit`；页面只有附件“打开 / 下载”。
4. **没有提交记录页。** `LmsSubmissions` 能返回每次提交的时间、文件、老师评分、评语、能否撤回，但只有 Agent 能看。
5. **附件不能页内预览。** 只能“打开”到校园网页窗口，或“下载”到本地；每个文件都要重新选保存位置。

频率：作业截止前每天多次；学期内每周 2–5 次进入课程看作业。

### 1.2 学习资料链

目标：找到某门课的资料，预览，下载需要的文件。

当前路径：思源学堂 → 选课程 → 学习资料 → 选资料活动 → 详情 → 附件“打开 / 下载”。

断点：

1. 没有跨课程资料库，也不能按文件名搜索；必须先知道资料在哪门课。
2. 资料活动本身不是文件列表，要点进详情才看到附件。
3. 没有 PDF / 图片 / 文本的页内预览。
4. 没有批量下载，也不能记住上次保存目录。
5. 没有“这门课有新资料”的提示。

频率：每周 2–5 次；考试周和布置大作业时上升。

### 1.3 成绩 / 考试链

目标：看本学期成绩和绩点，知道下一场考试在哪。

断点：

1. 成绩页一次性列出所有学期，没有学期筛选；后端 `Grades { term }` 已支持。
2. 没有加权平均、总绩点、已修学分、不及格学分统计；这些可以在前端算，但没做。
3. 考试页同样没有学期筛选，也没有“下一场考试”倒计时或按日期排序。
4. 没有出分提醒、考试提醒、加入系统日历。

频率：出分和考试周每天多次，平时接近零。

### 1.4 评教链

目标：期末一次性评完所有待评课程。

现状：待评列表、全选、评分档位、统一文字意见、预览、提交确认、逐份结果都已经有页面。

断点：

1. 没有“已评”列表；`Evaluations { finished:true }` 已支持。
2. 页面只能给所有课程填同一段评语；后端 `Prepare.comments` 支持按问卷单独评语，Agent 也能用，页面没接。
3. 没有评教截止提醒和“已评 / 待评”进度。

频率：每学期末 1 次，截止前集中。

### 1.5 自习链

目标：现在或某个时间段，找到有空的教室或图书馆座位。

断点：

1. 空闲教室每次都要重新选校区、楼宇、日期、节次；没有常用组合，也没有“现在有空”一键查询。
2. 教室结果有容量和类型，但不能按容量 / 类型筛选或排序。
3. 图书馆能看实时座位，但没有预约、签到、暂离、退座。本项目没有适配；参考项目 XJTUToolBox 已实现预约、换座、取消、入馆签到、中途离开 / 返回（`library/seats.py`），可以研究后独立适配。
4. 图书馆 `stats` 已返回各区域总座位 / 空余数，页面只显示当前区域，没有利用它做区域对比。

频率：学期内每周 1–3 次。

### 1.6 场馆链

目标：看场地、选时段、预订、取消。

断点：

1. 能看场馆、日期、时段、价格、余量和我的预订，但没有预订按钮，也没有取消。
2. 本项目只有查询适配，没有下单 / 取消。参考项目已实现预订和取消订单，预订需要滑块验证码（`app/threads/VenueThread.py`）。
3. 订单详情接口返回了日期、时段、场地、场馆，页面只显示一行摘要。

频率：有运动习惯的用户每周 1–2 次。

### 1.7 通知链

目标：看学校通知，必要时读正文。

断点：

1. 主页只接教务处 `dean` 一个栏目、20 条；后端和 Agent 支持 7 个栏目、最多 50 条。
2. 列表只有标题、分类、日期、链接，没有正文；点击必须进校园网页窗口。
3. 没有独立通知页、搜索、已读 / 未读、收藏、附件。
4. 主页的分类筛选只在已取回的 20 条里筛，不是全栏目。

频率：每天或每周。

### 1.8 课表链

目标：知道今天 / 本周上什么，临时改课表。

现状：周切换、今日高亮、课程块编辑、添加自建课程、隐藏、恢复、刷新都已实现。

断点：

1. 课表只有节次，没有具体上课时间，所以无法做上课提醒。参考项目有冬 / 夏两套作息表（`schedule/xjtu_time.py`），时间和切换日期需要核实后才能使用。
2. 没有导出、分享、订阅。
3. 没有和空闲教室、考试安排联动。

频率：每天多次。

## 20. 缺口分类

### 20.1 纯前端可做，不需要新接口

- 成绩学期筛选、加权平均、总绩点、学分统计。
- 考试学期筛选、按日期排序、下一场考试。
- 空闲教室常用组合、按容量 / 类型筛选和排序。
- 全校课程按校区筛选、结果分页或完整显示。
- 校历页显示当前教学周、假期倒计时。
- 评教“已评 / 待评”切换、按课程单独评语。
- 考勤日期范围、课程考勤页面。
- 校园卡自定义日期、待入账金额、消费筛选和统计。
- 图书馆各区域空余数对比、常用区域记忆。
- 场馆订单详情、按类型筛选。
- 通知多栏目页面、已读 / 未读、搜索。
- 主页待办、余额、空位等聚合卡片。
- LMS 课程搜索、活动搜索、未交作业筛选（前提是列表能拿到提交状态）。

### 20.2 后端要补字段或查询
