## 1. 原则

1. **风格不变，结构重做。** 沿用现有设计 token（`src/style.css`）、`src/components/ui/` 组件、lucide 图标、浅色主题和主题色。新增组件按同一套圆角、阴影、字号规则做，不另造视觉系统。
2. **任务优先。** 每页第一屏回答“我现在要做什么”：待交的作业、下一场考试、余额。明细放在后面。
3. **列表 + 详情。** 桌面端用分栏代替“点进去 → 返回”的层层跳转，选中项和详情同屏。
4. **数字有出处。** 每个指标都能点进它的明细。本地计算的指标带“按本页数据计算”说明。
5. **状态不只靠颜色。** 状态一律是“图标 + 文字”，颜色只是辅助。
6. **外链降级。** 校园网页入口只出现在“更多（⋯）”菜单，不做主按钮。

- 窗口默认 1120 × 760，最小 900 × 640；应用侧栏默认 140px，可收起到 56px（macOS 76px）。
- 现有 `.desktop-content-inner` 最大宽度 1040px，内边距 `28px 36px 40px`。畅行校园工作区改为**满宽**（新增 `is-wide`），因为它是分栏布局；内边距不变。

## 5. 视觉规则

### 5.1 字号与数字

| 用途            | 字号              | 字重                   |
| --------------- | ----------------- | ---------------------- |
| 页面标题        | 20px              | 600                    |
| 分区标题        | 15px              | 600                    |
| 详情标题        | 17px              | 600                    |
| 列表主标题      | 13px              | 500                    |
| 正文 / 表格     | 12.5px            | 400                    |
| 副标题 / 元信息 | 11.5–12px         | 400，`--text-tertiary` |
| 指标数值        | 22px（主页 26px） | 600，等宽数字          |
| 详情页大数字    | 32px              | 600                    |

数字、金额、时间一律 `font-variant-numeric: tabular-nums`。金额 `¥12.50`；支出不加负号，用文字“支出”区分，收入前加“+”。

### 5.2 状态色

现有 token 缺少警告色。新增：

| token            | 值        | 说明                                                                                       |
| ---------------- | --------- | ------------------------------------------------------------------------------------------ |
| `--warning`      | `#a15c00` | 白底对比度 5.19                                                                            |
| `--warning-soft` | `#fdf3e6` | `--warning` 在其上 4.73                                                                    |
| `--success-text` | `#246e44` | 浅绿底上的文字用它（5.60）；现有 `--success` 在 `--success-soft` 上只有 4.08，小字不够 4.5 |

| 语义        | 文字 / 图标        | 底色               | 图标（lucide） | 用于                                         |
| ----------- | ------------------ | ------------------ | -------------- | -------------------------------------------- |
| 完成        | `--success-text`   | `--success-soft`   | `CircleCheck`  | 已交、已评、正常出勤、预订成功               |
| 临近        | `--warning`        | `--warning-soft`   | `Clock`        | 24 小时内截止、迟到、余额低                  |
| 紧急 / 失败 | `--danger`         | `--danger-soft`    | `CircleAlert`  | 已逾期、3 小时内截止、不及格、缺勤、提交失败 |
| 进行中      | `--accent-text`    | `--accent-soft`    | `CircleDot`    | 待交、待评、进行中                           |
| 中性        | `--text-secondary` | `--surface-sunken` | `Circle`       | 已截止未交（不可再交）、无需考勤、未知       |
| 新          | `--accent-text`    | 无底，6px 圆点     | —              | 新作业、新资料、新成绩、未读通知             |

这些颜色只表示状态，不拿来区分系列。

### 5.3 时间文案

- 截止：`今天 23:59`、`明天 08:00`、`周五 23:59`（7 天内）、`11月12日 23:59`（更远）、`无截止时间`。
- 倒计时：`还剩 45 分钟`、`还剩 3 小时`、`还剩 2 天`、`已逾期 1 天`。超过 30 天不显示倒计时。
- 更新时间：`刚刚`、`5 分钟前`、`今天 16:20`、`10月29日`。
- 时区统一按 Asia/Shanghai。

### 5.4 间距与容器

- 卡片沿用 `.setting-card`：`--radius-lg`、`--shadow-sm`、行间分隔线。
- 分区内块与块间距 16px；指标条与下方内容 20px。
- 列表行高：单行 40px，两行 56px；行内左右 16px。
- 分栏之间 1px `--border` 分隔线，拖动把手 hover 时加粗到 2px 主题色。

### 5.5 动效

- 分栏切换、详情载入：150ms 淡入，沿用 `--duration-fast` / `--ease-out`。
- 选中指示条沿用现有滑动动画。
- `reduceMotion` 和 `prefers-reduced-motion` 下全部关闭。

## 6. 指标与图表

### 6.1 指标条（`StatRow`）

- 一行 3–5 个 `StatTile`，等宽，内容区窄时换成两行。
- `StatTile`：标签（12px，`--text-secondary`）· 数值（22px）· 补充说明（11.5px，例如“3 门未计入”“较上学期 +0.12”）。
- 可点击的指标块 hover 时显示 `--surface-hover` 并带右箭头，点击跳到对应明细或应用对应筛选。
- 加载中显示骨架；单个指标失败只显示“—”和重试图标，不影响同一行的其他指标。

### 6.2 图表

只在确实需要看趋势或构成时用图表，其余一律用数字或表格。

| 位置             | 图表           | 规则                                                                   |
| ---------------- | -------------- | ---------------------------------------------------------------------- |
| 成绩趋势 GRD-05  | 折线，单系列   | 主题色 2px 线，节点 8px；纵轴绩点，少于 2 个学期不显示                 |
| 每日支出 CARD-04 | 柱状，单系列   | 主题色，柱顶 4px 圆角，柱间 2px 间隔；今天高亮，其余降低不透明度       |
| 商户排行 CARD-05 | 横向条形       | 单一主题色，按金额降序，数值直接标在条尾                               |
| 出勤构成 ATT-02  | 一条堆叠条     | 正常 / 迟到 / 缺勤 / 请假用状态色，段间 2px 白隙；下方必须有图例和数字 |
| 区域空位 LIB-01  | 每行一个进度条 | 轨道 `--surface-sunken`，填充主题色；数字“32 / 120”标在右侧            |

通用规则：

- 纵轴只有一个，不做双轴。网格线用 `--divider`，坐标轴文字 11px `--text-tertiary`。
- 鼠标悬停显示数值提示；所有图表下方提供“查看数据”切换为表格，读屏用户直接读表格。
- 数值文字用文本色，不用系列色。
- 纯 SVG 实现，不引入图表库。

## 7. 写操作

### 7.1 预览面板（`WritePreviewPanel`）

所有写操作（作业提交、撤回、图书馆预约 / 签到、场馆预订 / 取消）都用同一个右侧面板。评教沿用现有页内预览流程。

```
┌ 提交作业 · 预览 ──────────────────────────┐
│ 数据结构 · 第 6 次作业                    │
│ 截止 今天 23:59 · 还剩 3 小时             │
│───────────────────────────────────────────│
│ 方式        正式提交（已交 1 / 可交 3 次）│
│ 文字        作业见附件。                  │
│ 文件        hw6.pdf            1.2 MB     │
│             main.cpp           8 KB       │
│ 合计        2 个文件 · 1.2 MB             │
│───────────────────────────────────────────│
│ ⚠ 这是第 2 次提交，老师可能只看最后一次。 │
│ 预览不会上传或提交，确认后只提交一次。    │
│                                           │
│               [返回修改]   [确认提交]     │
└───────────────────────────────────────────┘
```

- 顶部：操作对象、关键时间。
- 中部：用“属性 : 值”逐项列出将要发送的内容；文件列出名称和大小。
- 警告（`InlineAlert` 警告样式）：重复提交、已过截止、不可撤回、小组作业。
- 底部固定两个按钮：次要按钮“返回修改”，主按钮写明动作：“确认提交”“确认预订”“确认取消预订”。破坏性操作用 `danger`。
- 预览过期（5 分钟）后主按钮不可用，提示“预览已过期，请重新生成”。
- 场馆验证码在面板内完成，位于确认按钮上方。

### 7.2 结果

| 结果     | 显示                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| 成功     | 面板换成结果：完成图标、“已提交 16:21”、文件清单；按钮“查看提交记录”“完成”                                 |
| 被拒绝   | 错误提示 + 学校返回的原因；按钮“返回修改”                                                                  |
| 结果不明 | 警告提示：“提交结果未知，请先查看提交记录确认，确认前不要重复提交”；只有“查看提交记录”按钮，**不提供重试** |

## 8. 状态与反馈

| 状态           | 显示                                                                     |
| -------------- | ------------------------------------------------------------------------ |
| 首次加载       | 骨架屏：指标块、3–5 行列表占位；不用转圈                                 |
| 有缓存，刷新中 | 直接显示缓存；分区标题刷新图标旋转                                       |
| 缓存过期       | 分区标题下 `InlineAlert` 信息样式：“数据更新于 2 天前，可能已过期”+ 刷新 |
| 空             | `EmptyState`，说明为什么空、下一步做什么，例如“本学期没有待交作业”       |
| 部分失败       | 列表顶部警告条：“2 门课程读取失败”+ 展开查看 + 重试                      |
| 登录失效       | 整个分区 `EmptyState` 错误样式 + “重新登录”按钮                          |
| 网络错误       | 有缓存时显示缓存 + 错误条；没有缓存时 `EmptyState` + 重试                |
| 需要校园网     | 分区内说明“图书馆仅支持校园网直连”，不显示空列表                         |
| WebVPN 不可用  | 说明 + “建立直连会话”按钮                                                |
| 待接入         | 导航项置灰，分区内说明当前进度，不放假数据                               |

操作反馈：下载、保存、复制等轻量结果用页面底部的短暂提示（3 秒，可关闭）；写操作结果只在预览面板里显示。

## 10. 键盘与无障碍

- 快捷键：↑↓ 移动选中、Enter 打开、Esc 返回或关闭面板、⌘/Ctrl+F 聚焦当前分区搜索、⌘/Ctrl+R 刷新当前分区。
- 焦点环统一用 `--focus-ring`；分栏切换后焦点移到详情标题。
- 列表用 `role="listbox"` 或原生列表加 `aria-selected`；角标、状态、倒计时都有读屏文本。
- 文字对比度 ≥ 4.5，图形元素 ≥ 3；状态始终带图标和文字。
- 图表都有表格视图。
- 完整的无障碍验证需要用读屏软件人工测试，本规定只覆盖设计层面的要求。
