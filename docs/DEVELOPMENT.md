## 开发环境

- Node.js 22.12+ 与 npm；依赖版本由 `package-lock.json` 固定。
- Rust 工具链；依赖版本由 `src-tauri/Cargo.lock` 固定。
- macOS：Xcode Command Line Tools。
- Windows：Visual Studio C++ Build Tools 与 WebView2。

```sh
npm ci
npm run dev
```

`npm run dev` 启动原生 Tauri 窗口，Vite 仅为开发资源服务。单独 `npm run dev:frontend` 不能替代客户端验收。

macOS 构建独立 App：

```sh
npm run app:build -- --bundles app
open "src-tauri/target/release/bundle/macos/XJTU Launcher.app"
```

若 cargo 不在 PATH，先执行 `source "$HOME/.cargo/env"`。当前机器 Rust 位于 `/Users/bilibili/.cargo/bin/`。普通本地构建无需更新签名密钥。

## 持久化与运行边界

`~/.xjtu-launcher/auth.json` 保存校园账号、可选密码、会话与模型 API Key。按用户要求直接保存为本地 JSON，平时不用系统钥匙串。旧加密文件仅用于首次迁移；原文件与迁移失败的数据保留。不要把 auth.json 的真实内容放入调试输出。

普通配置、个人图片与安装插件在 Tauri 的应用目录。新配置字段必须提供默认值，以保留旧文件中的侧栏、插件和个人偏好。远端插件使用 `installed.json` 原子保存清单与来源；本地导入继续使用 `plugin.json`。

校园查询结果另存一份展示缓存，用于“先显示上次结果，再后台刷新”（0.4.0）。`src-tauri/src/cache.rs` 把结果写到应用数据目录的 `cache/<账号哈希>/<键哈希>.json`，读取始终按当前活动账号定位目录，因此切换账号后不会读到上一账号的数据；写入发生在产生结果的那次查询里：前端把缓存名随 `school_query` 传入，后端用该查询固定的账号快照选择目录，所以切换账号后才返回的慢请求只会写回旧账号，不会污染新账号。主动删除账号时整个账号目录一并删除。写入先落临时文件再重命名，单个条目上限 8 MB，读取失败或内容损坏一律视为未命中。前端 `src/cache.ts` 只负责读取与应用：页面先应用旧值，再发请求并用新结果替换；课表在启动后（已登录且已启用）立即读缓存并刷新。缓存只用于展示，不参与会话、登录、提交或任何判断，也不写入日志。实时性强的数据刻意不缓存：图书馆座位、场馆时段、评教列表与预览、思源学堂活动详情（含提交状态），这些页面只在请求返回后显示。缓存文件含学籍、成绩等个人信息，截图或排障时不要直接贴出 `cache/` 内容。

个人页的 MCP 模式由 `expose.rs` 提供，只监听 `127.0.0.1` 的 `POST /mcp`（默认 `39217`，端口来自配置 `mcpServerPort`，用户可改），不做请求认证。它复用 `agent::tools::builtin()` 的校园工具，按配置 `mcpServerEnabled` 与 `mcpServerDisabledTools` 启停和筛选；开关与端口在下次启动时恢复监听，端口被占用时保留原监听并给出原因。工具面覆盖全部现有校园查询与公开校园通知，以及两个写工具。`campus_lms_submit` 默认 `confirm=false` 只做预览，文件不上传、作业不提交；只有 `confirm=true` 才上传附件并提交。`campus_evaluations_submit` 不接受直接作答，必须先由 `campus_evaluations_preview` 生成预览并返回 `previewId`，再带 `confirm=true` 提交；预览 15 分钟过期，并与账号、会话代次绑定。作业写工具会再次校验活动必须是作业、文件必须是绝对路径的普通文件、扩展名在允许列表内、不位于 `.ssh` / `.xjtu-launcher` 等凭据目录、非符号链接，单文件 100 MB、单次 200 MB；任一写工具的提交结果不明时都直接返回“结果未知”，不自动重试。由于接口无请求认证，只应在本机使用，不得监听局域网；无论读写，都不转发外部 MCP 服务或读取凭据，工具本身也不返回密码、Cookie 或 API Key。

校园网页只复用账号所持有的会话，不能承诺所有学校网站免登录。窗口不得拥有启动器主窗口的 IPC 权限，账号变化时关闭旧窗口。后端查询必须固定账号快照并核对会话代次。

2026-10-24 登录探测与 WebVPN 落地（按用户反馈）：校园网下部分用户被带到 WebVPN 登录，另有人点“登录”后报“未收到预期的校园认证页面”。

探测：`network::probe` 原本要求考勤入口 302 到特定地址，或 200 页面同时含“西安交通大学”和“统一身份认证 / 考勤”，5 秒超时即回退 WebVPN；这与侧栏自检 `campus::reachable`（任何 <500 状态都算可达、10 秒预算）不一致，会出现自检说校园网可用、登录却走 WebVPN。现在两者统一：目标服务返回任何 <500 状态即直连，只有 5xx 或传输失败才回退；传输失败重试一次，每次 6 秒。

WebVPN：CAS 登录成功后 WebVPN 会先落在自己的门户页，旧代码靠页面含写死的 `西安交通大学WebVPN - 资源站点` 判定认证完成，学校改版或文案变化就会落到通用错误。现在不再匹配页面文案：在已经拿到 CAS 表单之后回到 WebVPN 主机的成功页面，就切到校园步骤，并用校园入口的实际响应验证 VPN 会话；如果代理把请求打回自己的登录页，明确提示“WebVPN 认证未完成”。其他非 CAS 落地页的错误会带上主机名，便于用户反馈定位。

Rust 114 项测试（10 项默认忽略）、Clippy（`-D warnings`）与格式检查通过。未用真实凭据做端到端验证：直连判定需要校园网环境，WebVPN 门户页需要真实账号登录，两项都待用户用受影响账号在开发版中实测。

## 字体

Windows 默认的微软雅黑在界面字号下偏粗，因此把 Noto Sans SC（SIL OFL 1.1）子集化后内嵌进应用：`src/assets/fonts/noto-sans-sc.woff2`（约 5.7 MB，覆盖常用拉丁、标点和 U+4E00–U+9FFF 汉字，可变字重 100–900）。样式表用 `@font-face` 注册为 `XJTU Sans SC`，仅在 `.platform-windows` 下排在字体栈首位；macOS 继续使用系统 SF Pro + 苹方。许可证文本 `src/assets/fonts/OFL.txt` 通过 `bundle.resources` 随应用分发。重新生成子集可用 `python3 -m fontTools.subset`，参数见提交记录。
