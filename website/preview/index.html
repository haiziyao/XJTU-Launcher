在 GitHub 看源码 常见问题

项目

XJTU Launcher 是给交大人用的桌面校园客户端，用 Rust + Tauri 2 + Vue 3 写成，遵循 MIT 协议。它不把网页塞进窗口里：登录、课表、成绩、思源学堂、Agent 与工作台都是原生界面。

团队

由个人发起并维护，不是学校官方项目。代码、Issue 和每个版本的更新记录都在 GitHub；想参与的人可以直接提交 PR，或者在上面三个方向下点赞投票。

理念

数据留在本机：凭据只写进 ~/.xjtu-launcher/auth.json，不经过任何服务器。会影响你数据的写操作——评教、交作业——必须先给出预览、由你确认才执行；没有暗改，也没有结果不明时的静默重试。

畅想

从「能查」到「能替你办」：接进更多校园流程，让 Agent 真正跑完多步任务；让插件与主题来自社区；把界面做得更安静、更好看。这三个方向就是我们对未来最直接的愿望。

安装

第一次打开

更多问题见 Q&A。

macOS

  1. 打开 DMG，把 XJTU Launcher 拖进「应用程序」。
  2. 提示「无法验证开发者」时，去「系统设置 → 隐私与安全性」点「仍要打开」。
  3. 每个新版本确认一次，之后直接启动。

Windows

  1. 运行 setup.exe，按向导完成安装。
  2. 出现「Windows 已保护你的电脑」时，点「更多信息」→「仍要运行」。
  3. 安装完成后从开始菜单启动。

应用没有 Apple 与 Windows 代码签名证书，系统提示不代表安装包损坏；可以用官网公布的 SHA256 核对后再打开。
