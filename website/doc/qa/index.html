常见问题

这是西安交通大学的官方应用吗？

不是。XJTU Launcher 是学生个人项目，与西安交通大学官方无关，也不代表学校立场。校园功能按公开的网页流程自行实现，接口变化或故障由项目自己跟进修复。

官网打不开或很慢怎么办？

域名备案完成前，官网可能无法通过域名直接访问，可以继续使用 GitHub Release 下载安装包。备案通过后会切换为 HTTPS 域名访问。

账号与安全

我的账号和密码会被上传吗？

不会。凭据只写入本机的 ~/.xjtu-launcher/auth.json，不经过任何服务器，也不会写进日志或截图。保存多个账号时，每个账号的凭据同样只留在本机。

切换或删除账号时会关闭旧的校园窗口、丢弃旧请求，缓存按账号隔离。

设置、缓存和我自己的文件放在哪里？

设置、凭据与缓存都在隐藏目录 ~/.xjtu-launcher；你自己的文件放在可见的 ~/Documents/xjtu-launcher-file，里面有 workspace/ 与 download/，位置可以在「应用设置 → 存储」里修改。

界面上一律显示 ~/... 路径，不显示账号名。

安装与系统

为什么 macOS 提示「无法验证开发者」？

安装包没有 Apple 开发者代码签名证书，所以 Gatekeeper 会拦截首次打开。到「系统设置 → 隐私与安全性」点「仍要打开」，每个新版本确认一次即可。

系统提示不代表安装包损坏。可以用官网公布的 SHA256 核对文件后再打开。

Windows 提示「已保护你的电脑」怎么办？

原因相同：没有 Windows 代码签名证书。点「更多信息」→「仍要运行」即可；同样建议先用 SHA256 校验安装包。

支持哪些系统？

目前提供 macOS（Apple 芯片与 Intel 芯片）和 Windows 10 / 11 x64 三个安装包，对应当前版本 v0.5.2。

使用

不在校园网里还能用吗？

查询请求会自动尝试回退到 WebVPN。个别系统在校外可能仍然不可用，以实际返回的结果为准。

会不会替我改课表、交作业或评教？

不会自动执行。所有会影响你数据的写操作都先给出预览，只有你明确要求并确认之后才提交；结果不明确时不会自动重试，取消也不声称「已撤回」。

应用怎么更新？

应用内置更新检查，更新包带签名校验。更新源地址默认只读，确认风险提示之后才能修改。
