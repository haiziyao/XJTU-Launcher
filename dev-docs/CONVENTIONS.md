# 开发约定手册

更新于 2026-10-28。本文件是项目规则的**唯一来源**；根目录 [AGENTS.md](../AGENTS.md) 只保留给 coding agent 的硬约束摘要。历史讨论在 [archive/](archive/)，不能用旧记录覆盖本文件。用户当次明确要求优先于历史文档；已授权的工作继续完成，不反复确认。

## 1. 产品方向

- 面向学生的本地校园客户端，优先 macOS，其次 Windows。技术栈固定为 **Rust + Tauri 2 + Vue 3 + TypeScript**。
- 产品承载校园账号、主页、课表、插件市场与 Agent。不建设启动器平台账号服务端；本地多校园账号和独立插件市场服务端在范围内。
- 校园业务优先研究本地 `/Users/bilibili/Developer/HZY/References/XJTUToolBox`，理解协议后独立适配。参考仓库中的功能、测试数据或设计图**不能**被写成已在本项目完成。
- 直接复用参考项目代码前，先核对 GPL-3.0 的分发要求；当前实现应保持独立重写。
- 不因名称是"启动器"就推导出快捷键唤出、命令搜索、启动本地应用等需求；未讨论的能力保持待定。

## 2. 设计与前端

1. 新前端**先有具体参考图**，且用户明确同意该设计并同意开始实现。技术栈、功能需求、要求出图或生成图片的同意，都**不等同于**设计获批。
2. 已批准基线：Claude 调整后的客户端（`7541e38`）及其后用户确认的现有页面。新增界面优先复用 `src/components/ui/`、现有设计 token 和图标，不临时另造视觉系统。
3. 设计审批按稿、按页面记录，不按关键词扩大：
   - `docs/design/plugin-market-v2/` 已获准并实施（市场三分区、服务端地址确认编辑、软件更新）。
   - `docs/design/campus-agent-v1/` 的 Agent 与评教页面**未获准**；旧稿只可借鉴骨架，视觉细节须重新确认。
   - 最小化桌宠的设计**未获准**，不得按设想直接实现。
4. 保持简约的桌面观感与简洁信息密度，使用系统原生标题栏。不要添加无关页脚、学校名、版本号、数量统计、状态灯、宣传卡片或占位演示对话。
5. 侧栏开关位于分隔线垂直中部，使用正式图标。展开宽度可拖动，向内侧拖过最窄宽度自动收起；收起宽度 macOS 为 **76px**（刚好容纳左上角窗口按钮），其他平台为 **56px**。
6. 默认以文字呈现资料，用户操作后再进入编辑态。
7. 按钮统一使用 `UiButton`（文字）与 `UiIconButton`（纯图标），不直接写 `.btn` 类，也不按页面另造图标按钮；变体、尺寸和例外见 [按钮与通用控件](UI_COMPONENTS.md)。新增通用交互优先抽成 `src/components/ui/` 组件，颜色、间距、圆角和动效沿用现有 token。
8. 最小化桌宠只在主窗口最小化时出现；关闭窗口仍是关闭，不是收起。桌宠窗口只能调用它自己的少量命令（查看设置与通知、还原主窗口、切换只保留桌宠、打开设置），**不得**获得主窗口的 IPC 能力。宠物精灵图仅限非商业使用并保留署名，MIT 不覆盖这些素材。
9. 课表只有节次、没有上课时间，**不要编造上课提醒**。
10. 开发与验收使用真正的 Tauri App（`npm run dev` 启动桌面窗口）；独立构建产物验收后留给用户查看。

## 3. 数据、账号与安全

- 凭据按用户决定保存在 `~/.xjtu-launcher/auth.json`，包含账号、可选密码、会话与模型 API Key。日常读写**不用**系统钥匙串；旧凭据只用于一次性迁移，不恢复历史加密存储方案。保存密码是可选项，接口不回读已存密码。
- 配置及凭据原子写入。新字段必须提供默认值，保持既有用户偏好；读取失败时报告错误并保留原文件。
- 切换 / 删除账号、重新认证及退出时，关闭旧校园窗口并隔离旧请求，保留账号代次（会话代次）检查。缓存与异步返回必须关联账号及会话代次。
- **不把密码、Cookie、API Key、令牌或私钥写入日志、截图和仓库**。测试优先使用合成数据；截取 `cache/`、`auth.json` 相关内容时同样脱敏。
- 不将校园凭据发送给插件市场服务。学校额外认证和会话过期状态应如实反馈。
- 课表自定义只改本机：自建课程、修改或隐藏学校课程都保存在 `timetable-custom.json`（按账号与学期隔离），不提交到学校系统；"恢复默认"总能取回学校原始内容。

## 4. 校园功能与写操作

- 查询与提交分开。评教先显示真实问卷对应的完整答案；**实际提交必须由用户主动触发**：界面里由用户点提交，Agent 工具必须拿到预览的 `previewId` 且用户明确要求后，才带 `confirm=true` 提交。
- 课表自定义的 Agent 工具（`campus_timetable_edit`）必须先返回改动前后的预览，用户明确同意后才带 `confirm=true` 生效。
- 结果不明（网络中断、5xx、无响应）时**不自动重试**，标记为未知并提示用户到学校系统确认；只有明确 4xx 拒绝才清理本次临时上传。取消只停止后续请求，不宣称撤回已发送内容。
- 批次结果逐项记录（`submitted` / `failed` / `skipped` / `cancelled` / `unknown`）。
- 校园网页只复用账号持有的会话，不能承诺所有学校网站免登录。校园窗口不得拥有主窗口的 IPC 权限；账号变化时关闭旧窗口。
- 后端查询必须固定账号快照并核对会话代次；`school_query` 只接受封闭的 `Query` 枚举，不接受任意 URL。
- 场馆预订、图书馆预约等写操作尚未开放给 Agent 或自动流程；开放前须按第 4 条增加预览与确认。

## 5. 插件与更新

- 插件只保留**启用开关**，侧栏入口跟随启用状态（2026-10-23 用户决定；`hiddenPlugins` 仅保留旧配置兼容）。
- 设置中插件服务地址默认只读：点击"确认更改"并确认危险提示后才进入编辑；保存或取消后重新锁定。
- 包版本、兼容性、摘要和来源必须验证；下载失败保留旧版本。已安装的同 ID 插件不能被另一来源无提示替换。
- 当前远端包只支持**声明式导航**；任意执行代码的插件运行时需要独立设计，不能借下载清单宣称已实现。校园 Rust 适配随 App 更新。
- 应用更新与插件更新来源独立；发布私钥只进入 GitHub Secret。安装前检查正在执行的校园、账号和插件任务，未来 Agent 任务也要接入。
- 正式插件服务器、应用更新端点和发布公钥尚未部署。**不要**写入设计稿示例域名、假版本或伪造可用插件。
- P0（2026-10-25）：应用更新镜像暂无域名与证书，内置地址临时写死为 `http://8.152.100.169/xjtu-launcher/latest.json`，客户端不额外提示用户。安装包仍由 minisign 校验，但清单可能被篡改。拿到域名后必须切回 HTTPS，并恢复 `config.rs`、`AppUpdateSettings.vue`、`prepare-release.mjs` 的 HTTPS-only 校验；详见 [P0.md](P0.md)。

## 6. 分支、提交与发布

- `main` 为 GitHub 默认分支，随发布更新为已验证的代码、面向用户的 README 与开发文档；当前最新发布版为 **0.5.2**，`main` 应与它一致。
- 日常开发在从发布提交拉出的 `codex/<主题>` 分支进行（当前 `codex/v0.5.2`），旧分支保留用于追溯。`dev` 停止作为独立主线，发布时与 `main` 一起快进。
- 需要隔离改动时新建 worktree，不因开始新任务随意覆盖现有工作。功能代码和开发专用资料尽量分别提交，按功能提交，发布前检查最终树。
- 推送分支、打标签与发布 Release **按用户当次明确要求执行**；2026-10-25 的用户要求已包含推送、发布与撤回 Release，同一发布周期内可继续操作，不擅自扩大到其他仓库或服务，也不变更远端分支保护。
- GitHub 使用 `git@github.com:haiziyao/XJTU-Launcher.git`，本仓库提交身份为 `haiziyao <1754203003@qq.com>`。使用仓库级 `git config --local`，不改全局身份和 SSH 密钥，不要覆盖原密钥。
- 升版本时同时修改 `package.json`、`package-lock.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` / `Cargo.lock`；发布流程见 [RELEASING.md](RELEASING.md)。

## 7. 验收与记录

- 小修改完成后直接说明；较大一批修改后统一检查、构建，避免每个小改都重复启动应用。验收使用真正的 Tauri App，并交付可独立运行的包；用户查看时保留窗口。
- 保存已有用户修改。完成必要测试后再说明验证范围。
- 必须区分四种状态：**代码实现**、**自动测试通过**、**真实校园 / 真机验证**、**用户验收**。不能把计划、设计稿或后端接线写成"已完成"。
- 明确未部署的服务和未测试的平台（Windows 实机、系统签名与公证）。
- 现有 Agent 和评教页面新稿仍未获准，不能按旧稿直接改动视觉；也不要因为接口已接通就把未验证的能力说成可用。
