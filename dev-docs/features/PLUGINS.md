# 插件格式与插件中心

插件中心只展示**随应用发布的内置插件**。清单在构建时编入二进制，没有远端市场、下载、安装、卸载或本地导入（2026-11-08 用户决定）。

## 插件中心

- 侧栏入口名为「插件中心」，页面分「校园广场」「拓展发明」「创新小港」「已安装插件」四个分区。
- 每行是插件名称、右侧一行简述和启用开关；单击行展开作者、版本、许可、分类与详细描述，有第三方素材时再显示署名，启用后可从这里打开插件页面。
- 只有启用开关会改动配置；`disabledPlugins` 记录关闭的插件 id，侧栏入口跟随启用状态。
- 默认启用：课程表、畅行校园、Agent 设置、主页主题、回放截取；默认关闭：桌面宠物、字体美化。
- 旧配置里的 `pluginServer`、`checkPluginUpdates` 与桌面宠物字段只读取一次，用于迁移，之后不再写入。

## 元数据与存储

插件的静态元数据**只写在** `plugins/<id>/plugin.json`，构建时通过 `include_str!` 编入二进制。不要另建中央 `plugins.json`，也不要把作者、版本、许可复制到 `config.json` 或 `plugins/settings/<id>.json`：前者会和清单漂移，后者是用户设置，不是插件身份。

- 用户启停状态在 `config.json` 的 `disabledPlugins`。
- 插件设置在各插件的 `plugins/settings/<id>.json`。
- 清单元数据随应用版本发布，用户不能改，也不会被旧配置覆盖。

`version` 是**插件自己的 semver**，与应用版本无关；改插件行为时按 patch / minor 递增。当前内置插件都从 `0.1.0` 开始，不要用应用版本冒充插件版本。

## 清单格式

每个内置插件位于 `plugins/<id>/plugin.json`，由 `src-tauri/src/plugins/manifest.rs` 通过 `include_str!` 读取并校验。

```json
{
  "schemaVersion": 1,
  "id": "cn.xjtu.timetable",
  "name": "课程表",
  "version": "0.1.0",
  "category": "campus",
  "author": "<实际作者>",
  "license": "MIT",
  "credits": "可选：第三方素材或改编代码的署名与许可说明。",
  "description": "查看学期课表与今日课程",
  "details": "从教务系统同步本学期课表，支持周次切换、课程编辑与自定义课程，主页会显示今天的课程。",
  "enabledByDefault": true,
  "icon": "calendar",
  "page": { "type": "timetable" },
  "widget": true
}
```

- `id`：必须是已登记的内置 id，未知 id 会被拒绝。
- `schemaVersion`：必须为 `1`。
- `category`：`campus`（校园广场）、`invention`（拓展发明）或 `lab`（创新小港）。
- `author`：**必填**，1–40 个字符；写实际作者，不要冒用他人署名。没有默认回落，缺作者会校验失败。历史内置插件保留原署名。
- `version`：必须为 `MAJOR.MINOR.PATCH`，可带 `-prerelease` 后缀；最多 32 个字符。
- `license`：可选，插件自身代码的许可，缺省 `MIT`；最多 32 个字符。第三方素材或改编代码的许可写进 `credits`。
- `credits`：可选，最多 300 个字符；只在有第三方素材、改编代码或需要署名时填写。
- `name`：1–30 个字符；`description` 最多 300 个字符；`details` 最多 600 个字符。
- `enabledByDefault`：新配置的初始状态；用户切换后以 `disabledPlugins` 为准。
- `page.type`：`timetable`、`campus`、`agentSettings`、`homeTheme`、`pptCapture`、`desktopPet`、`fontBeautify` 或 `links`。`links` 目前没有内置清单使用。
- `widget = true`：在主页「我的插件」区显示入口，目前只有课程表。
- `sidebar`：可选，缺省为 `true`。设为 `false` 时插件仍可在插件中心启停，但不占侧栏入口；回放截取从「思源学堂 → 课程回放」进入。
- `icon`：预留图标标识。

清单文件最多 64 KiB。校验失败会导致应用启动报错，不会静默跳过。

## 插件设置

插件自己的设置不写进 `config.json`，而是保存在：

```text
~/.xjtu-launcher/plugins/settings/<插件 id>.json
```

- 读写都按插件做值域校验：宠物角色、横条风格、通知来源、窗口位置；字体区域的字体名、字号、字重、行高与字距。非法值逐项回退默认，不让整页失败。
- 损坏或超大的插件文件只影响该插件，不阻止应用和配置加载。
- 写入使用原子替换，并与桌面宠物的位置保存共用同一把锁。
- 「设置 → 存储」里的可见文件夹另有 `plugin/` 放用户自备的插件资源，随文件夹迁移一起搬走。

Agent 设置插件的基础页包含「搜索服务 / 开启搜索服务 Agent」开关，控制社区广场是否可以把搜索问题发给默认模型服务。字段是 `config.json` 的 `agentSearchEnabled`，默认 `false`；它随应用配置保存，不写进插件设置文件。模型不可达时社区页的 Agent 模式仍会置灰，不只看这个开关。

### 桌面宠物

从设置页移入插件（2026-11-08）。主窗口最小化后出现浮动桌宠和通知横条；关闭窗口仍然是关闭。设置页提供角色、横条风格、只保留桌宠、台词气泡与通知来源。可预览；宠物窗口只拥有自己的少量命令，不获得主窗口 IPC。

### 字体美化

页面按四个类别设置字体、颜色、字号、字重、行高与字距：全局（按钮、导航、课表与未单独设置的地方）、标题、正文、代码；课表跟随全局，不再单独占一行。点击类别行会在下方就地展开编辑区（不再弹小窗），字体用标准下拉框，颜色用色块选择器，字号、字重、行高与字距各占一行并用滑杆调节；编辑区顶部标明预览所属类别与作用范围，样例和页面本身随拖动或选色实时变化，改动立即保存；关闭插件后恢复应用自带字体。字体名必须是安全字符（字母、数字、空格、`-`、`_`、`.`，最多 64 个字符），字号 8–48 px，字重按 100 取整，行高 1.0–2.5，字距 −1.0–5.0 px，颜色为空（跟随主题）或 `#rrggbb`。

2026-11-10 起页面内嵌字体库：霞鹜文楷、霞鹜新晰黑、思源宋体、更纱黑体四个官方来源，下载前显示预览，下载时在行内显示进度；更纱黑体下载官方 7z 包后在应用内解压。文件存放于 `~/.xjtu-launcher/resources/fonts/`，校验 SHA-256 后通过 `FontFace` 只在应用内加载，不写入系统字体目录。也支持添加本机 `.ttf` / `.otf` / `.woff` / `.woff2` 文件；「应用」会把字体设到全部四个类别（对应五个存储区域），字号等精细值保持不变。「取消应用」只把正在使用该字体的区域恢复系统字体，下载的文件保留，随时可以再次应用；「删除字体文件」收在行尾的「⋯」菜单里，确认后才删除，使用它的区域同时恢复系统字体。字体别名和字体选择弹窗改版尚未实现，见 [need-do](../planning/need-do.md)。

### 回放截取

从思源学堂课程回放中截取讲义页面，导出 PDF 或图片包。入口在「思源学堂 → 课程回放 → 课时详情 → 截取讲义」，清单用 `sidebar: false` 关闭侧栏入口。方案见 [回放截取插件方案](PLUGIN_PPT_CAPTURE.md)；真机截取与导出、Windows 端尚未验收。
